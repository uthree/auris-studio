# 物理楽器

[English](physical-instruments.md)

サウンドライブラリで **Physical Piano、Hammered Strings、Guitar、Electric Guitar、Bass、Strings、Mallet、Bell、Reeds、Whistles** を選べます。それぞれ固有の安定 ID（例 `auris.physical.guitar`）を持つ組み込みプラグインです。新しいメロディートラックは Physical Piano を使います。インストールするサンプルファイルはありません。**[Physical Choir](physical-choir.ja.md)** は別の楽器で、専用のページがあります。

どれも録音ではなく、楽器そのもののモデルです。回すのはハンマーのフェルト、弓の圧力、リードの硬さで、音はそこから決まります。

<a id="how-they-are-built"></a>
## 仕組み

これらの楽器で音を出すものは 2 種類あり、それぞれをあるがままに計算しています。

**ひとりでに鳴り続けるもの**（弦の部分音、音板やベルのモード、それらが駆動する響板や胴）は、部分音ごとに周波数と減衰を持つ減衰振動子の集まりです。ピアノの 1 音は、3 本の弦それぞれに最大 96 の部分音を持ちます。

**与え続けている間だけ鳴るもの**（弓の下の弦、管の中の空気）は、その中を回る波そのものです。ハンマー、弓の松脂、リード、空気ジェットは、その波を相手に 1 サンプルずつ解いています。

| 楽器 | モデル化しているもの | 調整するもの |
| --- | --- | --- |
| Piano | 押し込むほど硬くなるフェルトのハンマーと、駒を共有する 1〜3 本の弦。ダンパー、共鳴するほかの弦、響板、筐体のノック | 励振の硬さ、励振位置、ユニゾンの調律差、共鳴弦の響き、弦の剛性、リリース（ダンパー） |
| Hammered Strings | 浅い箱の上に張った細い複弦と、軽いハンマー | ハンマーの硬さ、打撃位置、弦の調律差、駒の減衰 |
| Guitar | 同時に 2 方向へ振動する撥弦と、空気共鳴と表板を持つ胴 | ピックの硬さ、撥弦位置、減衰、胴、ピックアップ比率（胴からサドルへ） |
| Electric Guitar | マグネットの下のスチール弦。アンプに入る前の信号 | ピック位置とピックアップ位置、トーン、ピックアップ Q、オクターブごとの減衰 |
| Bass | ピックアップで拾う、またはアップライトの胴で鳴らすベース弦 | 硬さ、位置、胴（0 はエレキ、1 はアップライト）、トーン |
| Strings | 奏者ごとの弦と、松脂が掴んでは放す弓。1〜4 人のセクション。バイオリン・ビオラ・チェロ・コントラバスの胴 | 弓圧、弓の速度・位置・応答、奏者の人数、楽器、ビブラート、レガート |
| Mallet | 共鳴管の上の音板。マリンバ、ビブラフォン、シロフォン、グロッケンシュピール、片端を固定したタイン | 音板の種類、マレットの硬さ、打撃位置、共鳴管、トレモロ |
| Bell | うなりながら鳴る対のモード。鋳造ベル、チューブラーベル、ハンドベル、シンギングボウル | ベルの種類、硬さ、縁のどこを叩くか、うなり |
| Reeds | リード側が閉じた円筒の気柱とリードの弁。クラリネット | 息の圧力、リードの硬さ、息の雑音、アタック、ビブラート、レガート |
| Whistles | 開いた管の歌口を横切る空気ジェット | 息の圧力、ジェット形状、息の雑音、アタック、ビブラート、レガート |

どのモデルにも **Level**、**Stereo Width**、**Live Quality**、**Render Quality** があります。

聴く前に知っておくとよい挙動がいくつかあります。

- **ピアノの各音域の音量は弦が決め、ハンマーは整音されています。** 弦が駒に渡せるのは自分が失うエネルギーだけなので、各音域が響板をどれだけ動かすかは、その音がどれだけ速く減衰するかで決まります。減衰は University of Iowa Musical Instrument Samples の Steinway B で、C ごとに 1 つずつ測った値です。ハンマーのフェルトも同じ録音に合わせて整音しています。調律師がグランドピアノのハンマーに針を入れるのと同じで、公表されているハンマーよりどの音域でも柔らかく、第 5 オクターブが最も柔らかくなっています。音は速く減衰してからゆっくり減衰します。駒が持っていくのはユニゾンの弦が共有する動きで、共有しない動きは残るからです。
- **どの鍵も隣の鍵と同じ大きさで鳴ります。** 響板や胴は共鳴の集まりで、無造作に足し合わせると穴があきます。2 つの共鳴の間に落ちた音が、ほとんど消えてしまうのです。ここではすべての共鳴を同じ向きで聞き、その下に駒そのものの放射を置いているので、打ち消し合いは起きません。残るのは楽器そのものの個性、つまりギターの空気共鳴と表板、バイオリンの胴です。それらが持ち上げる音は、奏者が覚えるのと同じように、少し弱く弾かれ、少し軽く擦られます。
- **打鍵は筐体を叩きます。** ピアノのどの音の下にも、鍵盤床と筐体が鳴る音程のないノックが約 3 分の 1 秒あります。どの鍵でも同じ大きさなので、低音ではほとんど聞こえず、最高音域では聞こえる音のかなりの部分を占めます。
- **ごく弱く押した鍵は音を出さず、ダンパーだけを上げます。** 低い C をベロシティ 1 で押さえたまま上の C を弾いて離すと、低い弦が上の音の高さで鳴り続けます。サステインペダルは、これをすべての弦で一度に行います。
- **Unison Detune** を 12 セントにするとホンキートンクになります。既定値は調律した直後のピアノで、高音のうなりは中音より速くなりません。
- **弓で擦った弦は、音になるとは限りません。** 弓圧が軽すぎると 1 周期に 2 回滑ってオクターブ上で鳴り、重すぎると弦が離れません。弓圧のコントロールはこの 2 つの間を動き、その弓の速度と位置で弦が受けられる最大の力に対する割合で決まります。各音はまずしっかり掴んでから設定した圧まで緩め、弦が滑った奏者は止まるまで弓を押し込みます。低い音で **Bow Pressure** を下げても表示ほど軽くならないのはこのためです。強い弓は音程を低く引っ張るので、各奏者は最初の数百ミリ秒をかけて指を動かし、音程を合わせ直します。
- **強く押すと、大きくなるのではなく明るくなります。** 音量は弓の速度です。弓圧は弦を回る角を鋭くし、低域はそのままで高域のスペクトルが数デシベル持ち上がります。
- **セクションは複数の奏者です。** それぞれが自分の弦を持ち、隣とは数セント、数ミリ秒、席ひとつ分ずれています。**Instrument** が Section のとき、低い音はチェロやコントラバスで弾かれ、その胴で鳴ります。
- **クラリネットは鳴り始めるまで静かです。** 息の強さは、その音が鳴り始める圧力からの差で測ります。そのため最も弱い息でもすべての音が鳴り、ほぼサイン波になります。リードが閉じる圧力の半分まで吹くと、ほぼ矩形波になります。タンギングした音はほぼ無音から始まり、数十ミリ秒で立ち上がります。録音したクラリネットと同じ始まり方です。
- **ベルのうなりは、どこを叩くかで変わります。** 各部分音は 1 Hz に満たない差を持つ 2 つの形でできていて、縁を叩いた場所が打撃をその 2 つに分けます。

<a id="controls-and-performance"></a>
## コントロールと演奏

ベロシティは音量だけでなく、楽器を励振するもの自体を変えます。強い打鍵ほどハンマーの接触が短く明るくなり、速い弓ほど強く押し、強い息ほどリードが大きく開きます。

**Decay**、**Damping**、**Release**、**Unison Detune** の変更は、鳴っている音にも届きます。硬さ、位置、剛性は打撃や撥弦に属するので、次の音から効きます。弦楽器の **Bow Position** はすぐに弓を動かします。

MIDI CC7 はチャンネル音量です。CC11 はエクスプレッションで、音量に加えて弓の速度と息にも作用します。CC1 は弓奏楽器と管楽器のビブラートを深くします。CC64 はピアノとビブラフォンのダンパーを上げます。鍵を離した後に踏むと、消えかけている音を捕まえます。ピッチベンドは鳴っている音に届き、上下 2 オクターブまで動きます。ピアノの **Release** はダンパーで、80 dB 減衰させるまでの時間です（低音ほど長く、F6 より上の鍵にはダンパーがありません）。

**Legato** をオンにすると、弦楽器・リード・ホイッスルは 1 本の旋律を弾きます。重なる音は新しいアタックなしで同じ弦や管を使い、最新の鍵を離すと、まだ押さえている鍵に戻ります。

**Live Quality** は作業中の再生、**Render Quality** は書き出し・フリーズ・バウンスに使われます。Draft は部分音を約 3 分の 1 に減らし、弓奏楽器と管楽器をプロジェクトのサンプルレートで動かします。Standard と High はその 2 倍で動かします。既定値は書き出しが High、再生が Standard です。

レンダリング結果は、オーディオデバイスが要求するブロックサイズによらず同じで、何度やっても同じです。ピアノは同時に 32 音、ほかは 12〜24 音を保持し、それを超えると、離鍵済みで最も静かな音が次の音に使われます。

<a id="composition"></a>
## 作曲

曲の仕様でネイティブ楽器を直接指定できます。

```toml
performance = "pop-band"
form = ["verse"]

[[part]]
name = "guitar"
role = "chords"
instrument = "auris.physical.guitar"
```

General MIDI のプログラムは、モデルをその楽器にするパッチとともに、これらの楽器に割り当てられます。

| プログラム | 楽器 |
| --- | --- |
| 0–3、6–7 | Piano。3 はホンキートンク、6–7 は硬く短いアタック |
| 8–13、108 | Mallet。チェレスタとグロッケンはスチールの音板、オルゴールとカリンバはタイン、ほかにビブラフォン、マリンバ、シロフォン |
| 14、112 | Bell。チューブラーベル、ハンドベル |
| 15 | Hammered Strings |
| 24–25、45 | Guitar。ナイロン、スチール、および短い撥弦としてのピチカート |
| 26–28、31 | Electric Guitar。28 はミュート |
| 32–35 | Bass。32 はアップライト |
| 40–44、48–49 | Strings。ソロのバイオリン・ビオラ・チェロ・コントラバスと、4 人のセクション |
| 71 | Reeds |
| 74、78 | Whistles。リコーダー、ホイッスル |

これらは Auris 自身の楽器の出発点となるパラメーターで、General MIDI のパッチを再現するものではありません。どのモデルにも当てはまらないプログラム（トランペット、ハープ、フルートなど）は、SoundFont の音か、セッションが報告するフォールバックのままです。SoundFont を明示的に指定した場合は、常にそのフォントが使われます。

<a id="looking-inside"></a>
## 内側を見る

トラックの楽器行から、楽器のパラメーターエディターを開きます。パラメーターの横には、鳴っている音を最大 4 つ、それぞれあるがままの形で描きます。両端の間に張られ、叩く・はじく・擦る位置に印の付いた弦、支えに載った音板、ベルの縁、歌口から開口端までの管の空気です。**どのボディにも触れられます。** ギターの弦を引いて離すとその位置ではじき、ピアノの弦を押すと打弦して離すとダンパーが下り、バイオリンの弦を押さえている間はその位置を弓で擦ります。

試聴用の鍵盤の下に **楽器の内側** があります。

- **胴** は、弦が駆動する響板や箱を面として描きます。低次モードがそれぞれ振動のどこにあるかを、板のモードの並びに沿って配置したものです。ピアノ、打弦楽器、ギター、アップライトベース、弓奏弦楽器にあります。
- **減衰** は、いちばん新しい音の最初の 24 部分音を直近 1.3 秒ぶん、高さをデシベルで描きます。ピアノの 2 段階の減衰、ホンキートンクのうなり、ベルのうなりは、聴くよりここで見たほうが分かります。
- **部分音** は、表示中のすべての音について、いま現在の同じスペクトルを示します。
- 最後のプロットは楽器を励振しているものです。打撃の 6 ミリ秒間のハンマーやマレットの力、弓の下での弦の速度の 1 周期（松脂が掴んでいる間は弓の速度で平らになり、離れると跳ね戻ります）、リードの開きの 1 周期、空気ジェットがエッジに当たる位置です。

面はドラッグで回せます。グラフィックスプロセッサがあればそこでシェーディングし、なくても同じ絵を描きます。

これらの絵は、楽器がすでに保持している状態から、エディターを開いている間だけ毎秒約 30 回読み出したものです。相対値でありメートル単位の実測ではなく、弦の形はスナップショットであってスローモーション映像ではありません。**Freeze** は音を鳴らしたまま絵を止めます。観察しても、聴こえる音は変わりません。

<a id="measured-against-recordings"></a>
## 録音との照合

各楽器は `tools/eval` のツールで実楽器の録音と照合しています。ツールはアプリケーションと同じコードでレンダリングします。以下は 2026-11-11 時点の値で、小さいほど録音に近いことを表します。

| 指標 | 録音 | 値 | 同じ録音に合わせ込んだモデル |
| --- | --- | --- | --- |
| ピアノ、メル距離 | Steinway B、C3〜G4、検証用 12 音 | 0.162 | 0.152 |
| ピアノ、部分音の減衰とエンベロープ | Steinway B、C1〜C8 | 4.8 dB、1.5 dB | 5.4 dB、2.0 dB |
| ピアノ、部分音のバランス・音域ごとの音量・ノック | 同上 | 4.0 dB、1.8 dB、5.1 dB | 4.2 dB、1.7 dB、3.4 dB |
| ギター、メル距離 | クラシックギター、検証用 44 音 | 0.167（Nylon guitar では 0.157） | 0.144 |
| ストリングス、メル距離 | ソロバイオリン、検証用 39 音 | 0.111 | 0.080 |
| リード、メル距離 | B♭ クラリネット、検証用の音高 | 0.043 | 0.054 |
| ホイッスル、定常部のメル距離 | ティンホイッスルの音階 | 0.017 | 0.018 |
| Hammered Strings、メル距離 | ハンマーダルシマー | 0.234 | 0.241 |

右端の列は、これらが置き換えた以前の楽器で、2 列目の録音そのものに合わせ込んだものです。合わせ込んだモデルが届く水準の目安であり、ピアノ、ギター、ストリングスはまだそこに届いていません。メル距離は音の最初の 1 秒のスペクトログラム距離で、定義は `tools/eval/physical_mel.py` にあります。ある録音にどれだけ近いかを表す値であり、音の良し悪しの評価ではありません。使った録音、各指標が比べるもの、各行のコマンドは[物理楽器を実録音と照合する](physical-copy-synthesis.ja.md)にあります。

C3〜G4 で、ピアノのピアニッシモはメゾフォルテより 12.7 dB 小さく、フォルティッシモは 7.0 dB 大きくなります。ベロシティはそれぞれ 0.35、0.65、0.95 です。録音の Steinway では 13.3 dB 小さく、9.6 dB 大きくなります。

隣り合う鍵どうしの音量差は、ピアノで 0.8 dB rms 以内、ギターとストリングスで 1.5 dB rms 以内です。


<a id="development-verification"></a>
## 開発時の検証

```sh
cargo test -p auris-synth -p auris-session
cargo test -p auris-gpui --bins physical
cargo run --release -p auris-synth --example physical_probe
cargo run --release -p auris-synth --example physical_bench

cargo build --release -p auris-synth --example physical_fit_render
uv run tools/eval/fetch_physical_reference.py target/physical-reference
uv run tools/eval/prepare_physical_reference.py target/physical-reference \
  --lock tools/eval/references/iowa-notes.json
uv run tools/eval/evaluate_physical_mel.py target/physical-reference \
  <変更前に凍結したワーカー> target/release/examples/physical_fit_render target/physical-eval
uv run tools/eval/piano_register.py target/piano-register prepare
uv run tools/eval/piano_register.py target/piano-register evaluate \
  <変更前に凍結したワーカー> target/release/examples/physical_fit_render target/piano-register/evaluation.json
```

テストは数値で検証します。すべてのモデルが 3 種類のサンプルレートで音域全体にわたって音程が合っていること、レンダリングがホストのブロックサイズに依存しないこと、オーディオスレッドで何もアロケートしないこと。ピアノが調律師のやり方どおりにストレッチされ、速く減衰してからゆっくり減衰すること。弓で擦った弦がどの弓圧でもヘルムホルツ運動をすること。クラリネットに偶数次倍音がなく、最も弱い息でも鳴ること。`physical_probe` は単音を鳴らして音量・音程・減衰を表示し、`physical_bench` は各モデルがプロセッサをどれだけ使うかを表示します。`physical_fit_render` は `tools/eval` の計測スクリプトが使うワーカーです。音に関わるものを変える前にワーカーのコピーを凍結しておき、変更後に両方を録音と照合します。録音は `target/` にダウンロードし、コミットしません。

整音の探索では、ワーカーの `dials` フィールドから `auris_synth::physical::calibration` のダイヤルを回します。候補ごとにビルドし直す必要はありません。これには `--features physical-calibration` が必要で、アプリケーションのビルドにダイヤルはありません。
