# 物理楽器

[English](physical-instruments.md)

サウンドライブラリで **Physical Piano、Hammered Strings、Guitar、Electric Guitar、Bass、Strings、Mallet、Bell、Reeds、Whistles** を選べます。それぞれ固有の安定 ID（例 `auris.physical.guitar`）を持つ組み込みプラグインです。新しいメロディートラックは Physical Piano を使います。インストールするサンプルファイルはありません。**[Physical Choir](physical-choir.ja.md)** は別の楽器で、専用のページがあります。

どれも録音ではなく、楽器そのもののモデルです。回すのはハンマーのフェルト、弓の圧力、リードの硬さで、音はそこから決まります。

<a id="how-they-are-built"></a>
## 仕組み

これらの楽器で音を出すものは 2 種類あり、それぞれをあるがままに計算しています。

**ひとりでに鳴り続けるもの**（弦の部分音、音板やベルのモード、それらが駆動する響板や胴）は、部分音ごとに周波数と減衰を持つ減衰振動子の集まりです。ピアノの 1 音は、3 本の弦それぞれに最大 96 の部分音を持ちます。

**与え続けている間だけ鳴るもの**（弓の下の弦、管の中の空気）は、その中を回る波そのものです。ハンマー、弓の松脂、リード、空気ジェットは、その波を相手に 1 サンプルずつ解いています。

| 楽器 | モデル化しているもの | 調整するもの |
| --- | --- | --- |
| Piano | 押し込むほど硬くなるフェルトのハンマーと、駒を共有する 1〜3 本の弦。ダンパー、共鳴するほかの弦、響板、筐体のノック | 励振の硬さ、励振位置、ユニゾンの調律差、共鳴弦の響き、弦の剛性、リリース（ダンパー） |
| Hammered Strings | 浅い箱の上に張った細い複弦と、軽いハンマー | ハンマーの硬さ、打撃位置、弦の調律差、駒の減衰 |
| Guitar | 同時に 2 方向へ振動する撥弦と、空気共鳴と表板を持つ胴。弾いていない開放弦が駒を通して共鳴します | ピックの硬さ、撥弦位置、減衰、胴、ピックアップ比率（胴からサドルへ）、奏法 |
| Electric Guitar | マグネットの下のスチール弦。アンプに入る前の信号 | ピック位置とピックアップ位置、トーン、ピックアップ Q、オクターブごとの減衰、奏法 |
| Bass | ピックアップで拾う、またはアップライトの胴で鳴らすベース弦。スラップでは、弦に打ち下ろす親指と、弦が当たるフレット | 硬さ、位置、胴（0 はエレキ、1 はアップライト）、トーン、奏法 |
| Strings | 奏者ごとの弦と、松脂が掴んでは放す弓。1〜4 人のセクション。バイオリン・ビオラ・チェロ・コントラバスの胴 | 弓圧、弓の速度・位置・応答、奏者の人数、楽器、ビブラート、レガート、奏法 |
| Mallet | 共鳴管の上の音板。マリンバ、ビブラフォン、シロフォン、グロッケンシュピール、片端を固定したタイン | 音板の種類、マレットの硬さ、打撃位置、共鳴管、トレモロ |
| Bell | うなりながら鳴る対のモード。鋳造ベル、チューブラーベル、ハンドベル、シンギングボウル | ベルの種類、硬さ、縁のどこを叩くか、うなり |
| Reeds | リード側が閉じた円筒の気柱とリードの弁。クラリネット | 息の圧力、リードの硬さ、息の雑音、アタック、ビブラート、レガート、奏法 |
| Whistles | 開いた管の歌口を横切る空気ジェット | 息の圧力、ジェット形状、息の雑音、アタック、ビブラート、レガート、奏法 |

どのモデルにも **Level**、**Stereo Width**、**Live Quality**、**Render Quality** があります。

聴く前に知っておくとよい挙動がいくつかあります。

- **ピアノの各音域の音量は弦が決め、ハンマーは整音されています。** 弦が駒に渡せるのは自分が失うエネルギーだけなので、各音域が響板をどれだけ動かすかは、その音がどれだけ速く減衰するかで決まります。減衰は University of Iowa Musical Instrument Samples の Steinway B で、C ごとに 1 つずつ測った値です。ハンマーのフェルトも同じ録音に合わせて整音しています。調律師がグランドピアノのハンマーに針を入れるのと同じで、公表されているハンマーよりどの音域でも柔らかく、第 5 オクターブが最も柔らかくなっています。音は速く減衰してからゆっくり減衰します。駒が持っていくのはユニゾンの弦が共有する動きで、共有しない動きは残るからです。
- **どの鍵も隣の鍵と同じ大きさで鳴ります。** 響板や胴は共鳴の集まりで、無造作に足し合わせると穴があきます。2 つの共鳴の間に落ちた音が、ほとんど消えてしまうのです。ここではすべての共鳴を同じ向きで聞き、その下に駒そのものの放射を置いているので、打ち消し合いは起きません。残るのは楽器そのものの個性、つまりギターの空気共鳴と表板、バイオリンの胴です。それらが持ち上げる音は、奏者が覚えるのと同じように、少し弱く弾かれ、少し軽く擦られます。
- **打鍵は筐体を叩きます。** ピアノのどの音の下にも、鍵盤床と筐体が鳴る音程のないノックが約 3 分の 1 秒あります。どの鍵でも同じ大きさなので、低音ではほとんど聞こえず、最高音域では聞こえる音のかなりの部分を占めます。
- **ギターの開放弦が応えます。** A3 を弾いて離すと、その音を第 2 倍音に持つ開放の 5 弦が、35 dB ほど下で鳴り続けます。どの開放弦の部分音の間にも落ちる B♭3 では、何も残りません。押さえている弦はその音自身なので、開放弦としては鳴りません。**Body** を下げたり、ピックアップ比率をサドル側に寄せたりすると、駒との結合も一緒に弱まります。
- **スラップしたベースでは、弦がフレットに当たります。** **Technique** を Slap にすると、E2 より低い音は親指の側面で叩き（サムピング）、E2 以上の音は指で引っ掛けて指板から引き離し、放します（プル）。どちらも弦を指板に向けて動かすので、弦はフレットにぶつかります。スラップの音はこの衝突です。最初の数十ミリ秒は金属が当たる硬い音が鳴り、弦がフレットまでの隙間より大きく振れているあいだは、ビリつきが続きます。フレットまでの隙間は叩く強さで変わらないので、強く叩くと当たる音が強くなり、あとに残る音はそれほど大きくなりません。**Excitation Position** は手の位置で、スラップでは最終フレットの上、32% です。この位置なら親指の下に指板があり、これよりブリッジ側では、親指はネックの端の先に落ちます。**Contact Hardness** は、親指の腹から骨までの硬さです。Thumb と Pop を選ぶと、すべての音をその弾き方で弾きます。サウンドの **Slap bass** は、これらをまとめて設定します。
- **ほかの楽器も Technique で弾き方を選べます。** ストリングスは、弓で弾く（Arco）、指で弾く（Pizzicato）、弓のトレモロ（Bowed tremolo）から選びます。ピチカートは、指板の端のあたりで弦を指で引いて放す奏法です。音は、弓が離れたあとの弦と同じように鳴って消えていきます。低い弦では数秒、いちばん高い弦では 1 秒足らずです。消えた音は、鍵を押さえたままでもそこで終わります。トレモロでは、各奏者が自分のタイミングで弓を 1 秒に 11 回ほど往復させます。各奏者は、弓を返してから次に返すまでのあいだの周期を聞いて指を合わせるので、音程は弓で弾いた音から数セント以内に収まります。ギターとベースは **Harmonics** を選べます。鳴らしたい音の 1 オクターブ下の弦を、弦の中点に指を軽く置いたまま弾く奏法です。中点で動く部分音は数十ミリ秒で止まり、残った音は押さえて弾いた音より澄んでいて、長く鳴ります。リードとホイッスルは **Flutter-tongue** を選べます。息に対して舌を 1 秒に 24 回ほど震わせる奏法です。低い音は管の応答が遅いので、高い音ほど深くは揺れません。
- **ごく弱く押した鍵は音を出さず、ダンパーだけを上げます。** 低い C をベロシティ 1 で押さえたまま上の C を弾いて離すと、低い弦が上の音の高さで鳴り続けます。サステインペダルは、これをすべての弦で一度に行います。
- **Unison Detune** を 12 セントにするとホンキートンクになります。既定値は調律した直後のピアノで、高音のうなりは中音より速くなりません。
- **弓で擦った弦は、音になるとは限りません。** 弓圧が軽すぎると 1 周期に 2 回滑ってオクターブ上で鳴り、重すぎると弦が離れません。弓圧のコントロールはこの 2 つの間を動き、その弓の速度と位置で弦が受けられる最大の力に対する割合で決まります。各音はまずしっかり掴んでから設定した圧まで緩め、弦が滑った奏者は止まるまで弓を押し込みます。低い音で **Bow Pressure** を下げても表示ほど軽くならないのはこのためです。強い弓は音程を低く引っ張るので、各奏者は最初の数百ミリ秒をかけて指を動かし、音程を合わせ直します。
- **強く押すと、大きくなるのではなく明るくなります。** 音量は弓の速度です。弓圧は弦を回る角を鋭くし、低域はそのままで高域のスペクトルが数デシベル持ち上がります。
- **セクションは複数の奏者です。** それぞれが自分の弦を持ち、隣とは数セント、数ミリ秒、席ひとつ分ずれています。**Instrument** が Section のとき、低い音はチェロやコントラバスで弾かれ、その胴で鳴ります。
- **クラリネットは鳴り始めるまで静かです。** 息の強さは、その音が鳴り始める圧力からの差で測ります。そのため最も弱い息でもすべての音が鳴り、ほぼサイン波になります。リードが閉じる圧力の半分まで吹くと、ほぼ矩形波になります。タンギングした音はほぼ無音から始まり、0.1 秒ほどで立ち上がります。録音したクラリネットと同じ始まり方です。弱い音は、伸ばすときより少し強い息で吹き始めます。そうしないと、鳴るまでに 1 秒近くかかるからです。音に混じる息のノイズも録音のクラリネットに合わせてあり、どの強さでも音の 33 dB ほど下にあって、1 kHz より上では小さくなります。
- **ベルのうなりは、どこを叩くかで変わります。** 各部分音は 1 Hz に満たない差を持つ 2 つの形でできていて、縁を叩いた場所が打撃をその 2 つに分けます。

<a id="controls-and-performance"></a>
## コントロールと演奏

ベロシティは音量だけでなく、楽器を励振するもの自体を変えます。強い打鍵ほどハンマーの接触が短く明るくなり、速い弓ほど強く押し、強い息ほどリードが大きく開きます。

**Decay**、**Damping**、**Release**、**Unison Detune** の変更は、鳴っている音にも届きます。硬さ、位置、剛性と、ストリングス・ギター・ベースの **Technique** は、打撃・撥弦・弓の一弾きに属するので、次の音から効きます。リードとホイッスルの **Technique** は、切り替えるとすぐに舌が震え始め、すぐに止まります。弦楽器の **Bow Position** はすぐに弓を動かします。

MIDI CC7 はチャンネル音量です。CC11 はエクスプレッションで、音量に加えて弓の速度と息にも作用します。CC1 は弓奏楽器と管楽器のビブラートを深くします。CC64 はピアノとビブラフォンのダンパーを上げます。鍵を離した後に踏むと、消えかけている音を捕まえます。CC64 はオンオフではなく踏み込みの深さとして読みます。最初の 4 分の 1 は遊びで、4 分の 1 から 4 分の 3 までの間にダンパーが弦から離れていきます。そのため、ハーフペダルでは離鍵後の音が止まらずに短くなります。CC66 はピアノのソステヌートで、踏んだ瞬間に上がっていたダンパーだけを上げたままにします。CC67 はソフトペダルで、踏んだまま打った音は 3 本の弦のうち 2 本を柔らかいフェルトで打つので、小さく暗い音になります。CC68 はレガート・フットスイッチです。弦楽器・リード・ホイッスルでは、踏んでいる間 **Legato** と同じようにスラーで弾きます。CC75（GM2 のディケイタイム）は中央が基準で、中央より下げると、ギターとベースではブリッジ側の弦に手のひらを置いたパームミュートになります。押さえたままの音でも高い倍音から先に短くなり、いちばん下まで下げると、ピックのクリックと短く暗い低音だけが残ります。鳴っている音にも開放弦にも効きます。中央より上げても何も変わりません。鍵を離すのは、押さえていた指を緩めることにあたり、音は **Release** の時間内に止まります。CC74（明るさ）も中央が基準で、弦楽器では弓を当てる位置になります。中央より上げると弓をブリッジ寄りに求め、最も近いところで **Bow Position** の 3 分の 1 になります（スル・ポンティチェロ）。ただし弓が実際に近づくのは、弦がまだ音を保てるところまでです。これは弓をふだん当てる位置とほぼ同じで、そこから先の分は弓を強く押し付けます。音は明るくなり、音量と音程は変わりません。**Bow Position** をそれよりブリッジ寄りに設定した場合も同じです。中央より下げると弓は指板の端の上へ移り、最大で 2 倍の距離まで離れます。弓圧も軽くなります（スル・タスト、柔らかくかすれた音）。CC65 をオンにすると、弦楽器・リード・ホイッスルでポルタメントがかかります。スラーでつながった音は、指をすぐに動かさず、CC5 が示す時間（50 分の 1 秒から 1.5 秒）をかけて次の音へ滑ります。ピッチベンドの速さは変わりません。打つ楽器と弾く楽器（ピアノ、ギター、ベース、マレット、ベル）では、CC74 は次に打つハンマー・ピック・マレット・ビーターの硬さです。中央より上げると硬く、下げると柔らかくなり、変わる幅は楽器自身の硬さのコントロールの半分までです。シロフォンの高音では、柔らかいマレットでもバーが跳ね返すのと同じ速さで離れてしまうので、硬くする方向にしか変わりません。CC2（ブレスコントローラー）は、エクスプレッションに加えてリードとホイッスルの息になります。値は最大が基準なので、送らないパートは今までどおりに鳴ります。ウィンドコントローラーから送った場合は、いちばん下の 1 割で息が尽きて鳴らなくなります。ビブラフォンでは、モジュレーションホイールが **Tremolo** より上にあるとき、ホイールがモーターを回します。CC64 は、チューブラーベルとハンマーダルシマーでもダンパーペダルとして働きます（ツィンバロムのペダルと同じです）。奏法はコントローラーではありません。MIDI にはスラップ、バイオリンのピチカート、ハーモニクスを伝えるメッセージがなく、General MIDI はそれぞれに専用のプログラムを割り当てています。ここでは各楽器の **Technique** コントロールがそれにあたり、パートの途中で弾き方を変えるときは、ほかのコントロールと同じようにオートメーションを書きます。ピッチベンドは鳴っている音に届き、上下 2 オクターブまで動きます。ピアノの **Release** はダンパーで、80 dB 減衰させるまでの時間です（低音ほど長く、F6 より上の鍵にはダンパーがありません）。

**Legato** をオンにすると、弦楽器・リード・ホイッスルは 1 本の旋律を弾きます。重なる音は新しいアタックなしで同じ弦や管を使い、最新の鍵を離すと、まだ押さえている鍵に戻ります。

**Live Quality** は作業中の再生、**Render Quality** は書き出し・フリーズ・バウンスに使われます。Draft は部分音を約 3 分の 1 に減らし、弓奏楽器と管楽器をプロジェクトのサンプルレートで動かします。Standard と High はその 2 倍で動かします。既定値は書き出しが High、再生が Standard です。

レンダリング結果は、オーディオデバイスが要求するブロックサイズによらず同じで、何度やっても同じです。ピアノは同時に 32 音、ほかは 12〜24 音を保持し、それを超えると、離鍵済みで最も静かな音が次の音に使われます。

<a id="composition"></a>
## 作曲

曲の仕様でネイティブ楽器を直接指定できます。

```toml
performance = "pop-band"
form = ["verse"]

[[part]]
name = "guitar"
role = "chords"
instrument = "auris.physical.guitar"
```

General MIDI のプログラムは、モデルをその楽器にするパッチとともに、これらの楽器に割り当てられます。

| プログラム | 楽器 |
| --- | --- |
| 0–3、6–7 | Piano。3 はホンキートンク、6–7 は硬く短いアタック |
| 8–13、108 | Mallet。チェレスタとグロッケンはスチールの音板、オルゴールとカリンバはタイン、ほかにビブラフォン、マリンバ、シロフォン |
| 14、112 | Bell。チューブラーベル、ハンドベル |
| 15 | Hammered Strings |
| 24–25 | Guitar。ナイロン、スチール |
| 26–28、31 | Electric Guitar。28 はミュート、31 はハーモニクス |
| 32–37 | Bass。32 はアップライト、36–37 はスラップ |
| 40–45、48–49 | Strings。ソロのバイオリン・ビオラ・チェロ・コントラバスと、4 人のセクション。44 はトレモロ、45 はピチカート |
| 71 | Reeds |
| 74、78 | Whistles。リコーダー、ホイッスル |

これらは Auris 自身の楽器の出発点となるパラメーターで、General MIDI のパッチを再現するものではありません。どのモデルにも当てはまらないプログラム（トランペット、ハープ、フルートなど）は、SoundFont の音か、セッションが報告するフォールバックのままです。SoundFont を明示的に指定した場合は、常にそのフォントが使われます。

<a id="looking-inside"></a>
## 内側を見る

トラックの楽器行から、楽器のパラメーターエディターを開きます。パラメーターの横には、鳴っている音を最大 4 つ、それぞれあるがままの形で描きます。両端の間に張られ、叩く・はじく・擦る位置に印の付いた弦、支えに載った音板、ベルの縁、歌口から開口端までの管の空気です。**どのボディにも触れられます。** ギターの弦を引いて離すとその位置ではじき、ピアノの弦を押すと打弦して離すとダンパーが下り、バイオリンの弦を押さえている間はその位置を弓で擦ります。

試聴用の鍵盤の下に **楽器の内側** があります。

- **胴** は、弦が駆動する響板や箱を面として描きます。低次モードがそれぞれ振動のどこにあるかを、板のモードの並びに沿って配置したものです。ピアノ、打弦楽器、ギター、アップライトベース、弓奏弦楽器にあります。
- **減衰** は、いちばん新しい音の最初の 24 部分音を直近 1.3 秒ぶん、高さをデシベルで描きます。ピアノの 2 段階の減衰、ホンキートンクのうなり、ベルのうなりは、聴くよりここで見たほうが分かります。
- **部分音** は、表示中のすべての音について、いま現在の同じスペクトルを示します。
- 最後のプロットは楽器を励振しているものです。打撃の 6 ミリ秒間のハンマーやマレットの力、弓の下での弦の速度の 1 周期（松脂が掴んでいる間は弓の速度で平らになり、離れると跳ね戻ります）、リードの開きの 1 周期、空気ジェットがエッジに当たる位置です。

面はドラッグで回せます。グラフィックスプロセッサがあればそこでシェーディングし、なくても同じ絵を描きます。

これらの絵は、楽器がすでに保持している状態から、エディターを開いている間だけ毎秒約 30 回読み出したものです。相対値でありメートル単位の実測ではなく、弦の形はスナップショットであってスローモーション映像ではありません。**Freeze** は音を鳴らしたまま絵を止めます。観察しても、聴こえる音は変わりません。

<a id="measured-against-recordings"></a>
## 録音との照合

各楽器は `tools/eval` のツールで実楽器の録音と照合しています。ツールはアプリケーションと同じコードでレンダリングします。以下は 2026-11-11 時点の値で、小さいほど録音に近いことを表します。

| 指標 | 録音 | 値 | 同じ録音に合わせ込んだモデル |
| --- | --- | --- | --- |
| ピアノ、メル距離 | Steinway B、C3〜G4、検証用 12 音 | 0.162 | 0.152 |
| ピアノ、部分音の減衰とエンベロープ | Steinway B、C1〜C8 | 4.9 dB、1.4 dB | 5.4 dB、2.0 dB |
| ピアノ、部分音のバランス・音域ごとの音量・ノック | 同上 | 4.0 dB、1.8 dB、5.1 dB | 4.2 dB、1.7 dB、3.4 dB |
| ギター、メル距離 | クラシックギター、検証用 44 音 | 0.160（Nylon guitar では 0.154） | 0.144 |
| ストリングス、メル距離 | ソロバイオリン、検証用 39 音 | 0.111 | 0.080 |
| リード、メル距離 | B♭ クラリネット、検証用の音高 | 0.041 | 0.054 |
| ホイッスル、定常部のメル距離 | ティンホイッスルの音階 | 0.017 | 0.018 |
| Hammered Strings、メル距離 | ハンマーダルシマー | 0.234 | 0.241 |

右端の列は、これらが置き換えた以前の楽器で、2 列目の録音そのものに合わせ込んだものです。合わせ込んだモデルが届く水準の目安であり、ピアノ、ギター、ストリングスはまだそこに届いていません。メル距離は音の最初の 1 秒のスペクトログラム距離で、定義は `tools/eval/physical_mel.py` にあります。ある録音にどれだけ近いかを表す値であり、音の良し悪しの評価ではありません。使った録音、各指標が比べるもの、各行のコマンドは[物理楽器を実録音と照合する](physical-copy-synthesis.ja.md)にあります。

C3〜G4 で、ピアノのピアニッシモはメゾフォルテより 12.7 dB 小さく、フォルティッシモは 7.0 dB 大きくなります。ベロシティはそれぞれ 0.35、0.65、0.95 です。録音の Steinway では 13.3 dB 小さく、9.6 dB 大きくなります。

隣り合う鍵どうしの音量差は、ピアノで 0.8 dB rms 以内、ギターとストリングスで 1.5 dB rms 以内です。

ピアノの低音は 2026-11-24 に整音し直しました。同じ Steinway の C に加えて、G1、C2、G2 とも照合しています。低い音の打鍵直後は、1〜8 kHz が録音より 6〜20 dB 小さかったのが、11 dB 以内になりました。下の 2 オクターブのハンマーを硬くし、1 本または 2 本の弦を打つ音では、弦ごとの部分音を 96 本から 144 本に増やしています。96 本では、最低音の C が 3 kHz で途切れていました。巻線の弦の 2 つの振動面と、低音の 2 本弦は、高音のユニゾンより 100 分の数 Hz だけ離してあります。表の指標では、エンベロープが 1.5 dB から 1.4 dB に、部分音ごとの減衰が 4.8 dB から 4.9 dB に動きました。部分音のバランス、音域ごとの音量、ノックは変わらず、C3 より上の鍵は何も変わっていません。

クラリネットの息のノイズは、同じ録音の定常部で、倍音のあいだにある成分として読みます。録音ではピアニッシモからフォルティッシモまで音の 31〜35 dB 下にあり、モデルでは 33〜35 dB 下です。以前は 21〜31 dB 下で、2 kHz より上では倍音より大きい一様なノイズでした。ピアニッシモの音が音量の 1 割から 9 割まで立ち上がる時間は、録音で 134 ms、モデルで 131 ms です（以前は 277 ms）。上の表のリードの行は 2026-11-24 に読み直しました。

2026-11-24 に、すべての楽器を音域の端から端まで、強弱 3 段階と各コントロールの両端で鳴らし、音程、倍音のあいだの成分、鳴り方のむらを調べました。問題が 4 つ見つかり、直しています。

弓をふだんの 3 分の 1 までブリッジに寄せると（CC74 の最大にあたります）、弓奏の 185 音のうち 172 音が荒れ、148 音は音程が 5 セント以上ずれていました。ずれは最大で 88 セントです。弦の運動を保つのに必要な最小の弓圧は、弓がブリッジに近いほど距離の 2 乗に反比例して大きくなります。一方、この弦が耐えられる最大の弓圧は、測ってみると近づけても増えませんでした。そのためブリッジ寄りでは両方を満たす弓圧がなく、弦の倍音鳴りが止まるまで押し付ける奏者が、音を潰していました。いまは、弦が音を保てる位置で弓を止め、残りの分は強く押し付けます。荒れる音は 185 音中 4 音、音程がずれる音は 13 音になりました。残りはほとんどが A♯6 より上の音で、ここでは押し付けた弓がまだ音程を下げます。弓をふだんの位置に当てたときの音は変わっていません。

クラリネットは、息の圧力を 9 割にして強く吹くと最大 8 セント高く、ホイッスルは最高音域で 4 セント低く鳴っていました。どちらも、どの圧力でも 1.5 セント以内になりました。弱い音にフラッタータンギングをかけると、ほとんど息の音だけになり、同じ音を普通に吹いたときより 13〜28 dB 小さくなっていました。いまは約 6 dB 小さいだけです。ギターのハーモニクスは、聞こえる音ではなく、弾いている弦の音を基準に音量をならしていました。隣り合うハーモニクスとの音量差は、実効値で 2.9 dB から 1.8 dB になりました。

見つけたまま残したものが 1 つあります。弓奏のコントラバスの最低音（E1 と F1）は、3 度上の録音の音より荒れています。

このとき、クラシックギターの録音の 1 弦は、音の最初の 0.5 秒で 2〜4 kHz が基音より約 17 dB 小さく、モデルでは 35 dB 小さいと分かりました。プレーン弦を速く離すだけでは、上の表のメル距離が悪くなりました。そこで同じ日に、同じ録音と部分音ごとに比べ直しました。各音の最初の 16 個の部分音について、最初の 0.1 秒の大きさと、減衰の速さを読んでいます。合っていなかったのは次の 3 つで、まとめて直しました。

- **撥弦。** どの弦も同じ速さで指から離れていました。録音の 6 弦はそれで合っています。波が 4 倍の速さで伝わる 1 弦は、第 8 部分音より上が、弱く弾いて 15 dB、中くらいで 22 dB、強く弾いて 34 dB 大きく出ていました。今は、波の速い弦ほど早く指を離れ、強く弾くほどさらに早く離れます。
- **弦の損失。** 録音の部分音は高いものほど速く減衰し、1 弦の第 16 部分音は 1 秒あたり約 200 dB で落ちます。モデルは 50 dB に届いていませんでした。ギターの **Damping** の初期値を 50% にして、弦の損失を録音のギターに合わせました。基音の長さが変わらないように、**Decay** の初期値は 12.5 秒にしています。
- **胴。** 録音のギターは、150〜350 Hz の大きさを基準にすると、400 Hz〜1.5 kHz がモデルの胴より約 5 dB 小さくなっています。高い音の第 2 部分音が強すぎたのはこのためです。空気共鳴と表板の共鳴の間に谷もありません。そこで、駒そのものの放射を 500 Hz までにし、350 Hz より上の板の共鳴を下げ、空気共鳴を広く弱くしました。

すべての弦と強弱を通して、部分音の大きさと録音との差は 6.3 dB から 3.6 dB に、減衰の差は 1 秒あたり 21 dB から 10 dB になりました。表のメル距離は 0.167 から 0.160 に、Nylon guitar では 0.157 から 0.154 になっています。1 弦の最初の 0.5 秒の 2〜4 kHz は、録音より 18 dB 小さかったのが 8 dB 小さいところまで来ました。6 弦の開放の基音は、まだ録音より 12 dB 強いままです。エレキギターとベースはそれぞれの録音に合わせてあるので、変えていません。コントロールの値を書き出して保存したギターは、保存したときの Damping と Decay のままなので、高い倍音が明るくなり、以前と同じ長さで鳴ります。Body エフェクトのギターも同じ胴なので、一緒に変わりました。

ベースも同じ日に、スラップの調整に使った 3 本のエレキベースの録音と照合しました。指弾きの 60 音で、どれも弾いてから 2〜3 秒鳴らしたままの音です。録音では音量が 1 秒あたり 3.7 dB、基音が 3.5 dB 下がります。モデルは 12.6 dB と 12.0 dB で、約 3 倍の速さで消えていました。録音の基音は、開放弦と 3 フレットではどの弦でも 1 秒あたり約 2 dB しか下がらず、同じ弦の 1 オクターブ上ではその 2 倍近く下がります。モデルは、どの弦で弾いても、高い音ほど速く減衰していました。

ベースの **Decay** の初期値を 35 秒にして、開放弦が録音と同じ長さで鳴るようにしました。押さえた弦は、短くなった分だけ速く減衰します。音の高さだけでは、音は短くなりません。巻線の弦の 2 つの損失は分けて決めました。摩擦を多く、曲げを少なくしています。これまでは、E 弦の 1〜2 kHz の部分音が 1 秒あたり 74 dB で消えていました（録音は 30 dB）。音ごとに比べた音量の減衰の差は、1 秒あたり 8.8 dB から 1.1 dB になりました。部分音の減衰の差は 6〜8 dB から 2.5〜5 dB です。また、強く弾いた音は 12 セント高く始まっていて、これだけ長く鳴る弦では数秒残ります。録音の音は、最初の 0.5 秒が 2 秒後より 0.7 セント高いだけなので、最も強く弾いたときで 2 セントにしました。Upright bass は以前の 7 秒のままです。スラップが音に与える変化は 0.5 dB 以内しか動いておらず、下の表はこのベースで読み直した値です。

ギターのように高い弦ほど早く指を離れるかどうかは、ベースとエレキギターでも調べました。ピックアップは各弦の部分音を櫛形に拾い、その谷の位置は弦ごと、録音の楽器ごとに違います。このため 1 つの帯域が 20 dB 動き、ギターのように帯域ごとに弦を比べることができません。ベースでは、ギターの法則を入れても入れなくても、弦のあいだの録音とのずれは実効値で 7.8 dB のままでした。ベースは、どの弦も同じ折れ点のままにしています。

エレキギターは、合わせ直して決めました。録音のストラトキャスターのクリーンの 48 音（両方のピックアップ）にすべてのコントロールを合わせ、別の音高の 46 音で読んでいます。合わせ方は、全弦で同じ折れ点にした場合と、法則のべき指数を自由にした場合の 2 通りです。法則なしでは、いちばん硬いピックに行き着きます。法則ありでは、柔らかいピックとべき指数 1.3 に落ち着き、検証用の音の誤差が 5% 小さくなりました（0.134 に対して 0.127。差の区間は 0 を含みません）。どちらの当てはめも、ピックアップを弦の 24% と 7% に置きました。これはストラトキャスターの実際の位置で、櫛の谷だけから求めた位置とも合います。エレキギターには法則をべき指数 1.4 で入れ、ピックを柔らかくしました。**Contact Hardness** の初期値は 0.6 から 0.3 になっています。ほかのコントロールを変えないままで、検証用の音の誤差は 0.150 から 0.145 になり、46 音のうち 33 音が録音に近づきました。録音は 1 つの強さでしか弾かれていないので、ギターと違い、強く弾いてもべき指数は増えません。

エレキギターには、決めきれていないことが 2 つあります。櫛の谷だけから読むと、同じ録音は「駒から弦の 3.5% の位置をピッキングしていて、法則はない」とも説明できます。その場合の録音の部分音とのずれは 4.3 dB で、もっと離れた位置のピッキングに法則を足した場合は 5.1 dB です。ただ、この楽器はピックを 5% より駒寄りに置けず、5% に置くと低い弦が明るくなりすぎます。もう 1 つは、同じ当てはめが撥弦以外の変更も求めていることです。**Damping** を初期値の 0.03 から 0.3 付近にすると検証用の音の誤差は 0.127 になりますが、今回は取り入れていません。

スラップベースは、3 本のエレキベースの録音と照合しています。録音には、同じ音を指弾き、サムピング、プルで弾いたものがあります。比べるのは、スラップが音をどう変えるかです。どの指標も、同じ音を指で弾いたときの値との差で読みます。下の表は、モデルの調整に使わなかった音での平均で、2026-11-24 時点の値です。

| スラップと指弾きの差 | 録音、サム | モデル | 録音、プル | モデル |
| --- | --- | --- | --- | --- |
| 音量 | −3.3 dB | −2.2 dB | −2.1 dB | −3.9 dB |
| 当たる音と、残る音の比 | 6.0 dB | 3.1 dB | 2.1 dB | 4.1 dB |
| ピークと音全体の比 | 6.0 dB | 5.1 dB | 2.6 dB | 3.8 dB |
| 基音が占める割合 | −4.7 dB | −3.8 dB | −0.6 dB | −6.2 dB |
| 0.1 秒から 0.5 秒までの減衰 | 0.5 dB | 1.3 dB | 0.7 dB | 1.6 dB |

録音からいちばん離れているのは、サムの当たる音です。残る音に対する大きさが、録音より 3 dB 小さくなっています。

バイオリンのピチカートは、Iowa の録音の D 弦と E 弦の音で減衰の速さを比べました。最大音量の 5 dB 下から 25 dB 下までで読むと、録音は 1 秒あたり 17〜310 dB、モデルは 66〜450 dB で、モデルと録音の比の中央値は 1.25 です。録音の開放弦は、隣の押さえた音の 4 倍長く鳴りますが、モデルは開放弦と押さえた弦を区別しません。トレモロ、ハーモニクス、フラッタータンギングは録音とは照合しておらず、それぞれの奏法として成り立っているかをテストで確かめています。

## 開発時の検証

```sh
cargo test -p auris-synth -p auris-session
cargo test -p auris-gpui --bins physical
cargo run --release -p auris-synth --example physical_probe
cargo run --release -p auris-synth --example physical_bench

cargo build --release -p auris-synth --example physical_fit_render
uv run tools/eval/fetch_physical_reference.py target/physical-reference
uv run tools/eval/prepare_physical_reference.py target/physical-reference \
  --lock tools/eval/references/iowa-notes.json
uv run tools/eval/evaluate_physical_mel.py target/physical-reference \
  <変更前に凍結したワーカー> target/release/examples/physical_fit_render target/physical-eval
uv run tools/eval/piano_register.py target/piano-register prepare
uv run tools/eval/piano_register.py target/piano-register evaluate \
  <変更前に凍結したワーカー> target/release/examples/physical_fit_render target/piano-register/evaluation.json
uv run tools/eval/bass_slap.py fetch target/slap-reference
uv run tools/eval/bass_slap.py measure target/slap-reference \
  target/release/examples/physical_fit_render target/slap-reference/measure.json
```

テストは数値で検証します。すべてのモデルが 3 種類のサンプルレートで音域全体にわたって音程が合っていること、レンダリングがホストのブロックサイズに依存しないこと、オーディオスレッドで何もアロケートしないこと。ピアノが調律師のやり方どおりにストレッチされ、速く減衰してからゆっくり減衰すること。弓で擦った弦がどの弓圧でもヘルムホルツ運動をすること。クラリネットに偶数次倍音がなく、最も弱い息でも鳴ること。スラップした弦がフレットからエネルギーを受け取らず、親指と弦のエネルギーの合計が、親指が持ってきた分を超えないこと。ピチカートの音が鍵を押さえたままでも終わること、トレモロの弓が 1 秒に十数回返ること、ハーモニクスで 1 オクターブ下の成分が 0.1 秒以内に消えること、フラッターをかけても音程が変わらないこと。`physical_probe` は単音を鳴らして音量・音程・減衰を表示し、`physical_bench` は各モデルがプロセッサをどれだけ使うかを表示します。`physical_fit_render` は `tools/eval` の計測スクリプトが使うワーカーです。音に関わるものを変える前にワーカーのコピーを凍結しておき、変更後に両方を録音と照合します。録音は `target/` にダウンロードし、コミットしません。

整音の探索では、ワーカーの `dials` フィールドから `auris_synth::physical::calibration` のダイヤルを回します。候補ごとにビルドし直す必要はありません。これには `--features physical-calibration` が必要で、アプリケーションのビルドにダイヤルはありません。
