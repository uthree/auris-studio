# ギターアンプの改良

[English](amp-refinement.md)

現在のアンプは、対称なソフトクリッピング段を1つ使います。

```text
y = tanh(10^(drive_db / 20) * x)
```

トーンスタック、8倍オーバーサンプリング、257タップのBlackman窓FIR、報告レイテンシー32フレーム、DCブロッカー、解析的キャビネットは変更していません。以前の2段構成の測定値は過去の診断として残しています。

Driveの範囲は0〜42 dBから0〜48 dBに拡張しました。EGFxSetの訓練用48音すべてでDriveを適合し、単純なtanh基準にも同じ0〜48 dBの上限を使いました。適合値は47.994488 dB、単純基準は47.994049 dBでした。ネイティブ48 kHz出力を訓練用48音と検証用の未使用46音について8音ずつレンダリングし、固定ログメル指標のため24 kHzに再サンプリングしました。

| コホート | 過去の2段アンプ | 改良アンプ | 単純tanh |
| --- | ---: | ---: | ---: |
| 訓練 | 0.08384799459 | 0.06936643792 | 0.07075090728 |
| 検証 | 0.07967830676 | 0.06622412116 | 0.06733945544 |

改良モデルは、検証メル誤差を過去の2段候補に対して16.89%、別個に適合した単純tanhに対して1.66%下げました。訓練での低下はそれぞれ17.27%と1.96%です。これらは未使用ピッチ分割の記述的指標であり、知覚スコアでも特定の市販回路を再現した証拠でもありません。

16.89%の比較には飽和方式の変更、拡張したDrive範囲、新しい訓練適合が含まれ、単一の回路選択だけを分離したものではありません。新しい適合値はDrive上限に達し、4つのコントロールの探索ではフラットEQの初期点を保持します。1.66%の比較では、両方の現行モデルに同じ上限を使います。どちらもキャビネットをバイパスした同じ録音DIを受け取ります。2,000回の再標本化によるペア付きピッチブートストラップでは、検証メル差の区間は過去のアンプに対して[−0.017270, −0.009835]、単純tanhに対して[−0.001333, −0.000912]でした。このコホートには録音済みのスピーカー・キャビネット目標はありません。

既存9プリセットのWAVハッシュ、記号行、Audioboxスコアは変わりません。これらのプリセットは変更したプラグインを実行しません。この回帰の記録は `tools/eval/references/physical-next-regressions.json` にあります。

音ごとの完全なレポートは `tools/eval/references/amp-refinement.json`、適合パラメーターは `tools/eval/references/amp-refinement-fit.json`、再現可能な分割評価器は `tools/eval/amp_refinement.py` です。レポートには結果を監査するためのソース、レンダラー、指標設定が残っています。
