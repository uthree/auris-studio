# 物理ピアノのストレッチ調律

[English](piano-stretch-tuning.md)

Physical Piano は、基音を平均律ちょうどには置きません。弦には硬さがあるため、倍音は整数倍より
高くなります。すべての基音を平均律（A4 = 440 Hz）に置いたピアノでは、次の2つが同時に起きます。

* **低音が高く聞こえる。** 低い音の音高は倍音で聞こえるため、音は基音より高く聞こえます。
* **すべてのオクターブがうなる。** 下の音の第2部分音は上の音の基音より高く、第4部分音は
  上の音の第2部分音よりさらに高くなります。

## 調律のしかた

ピアノは調律師と同じやり方で調律されます。A4 から外側へ、各オクターブを、2つの純正な
オクターブの中間まで広げます。A2 から上では、2:1（下の音の第2部分音を上の音の基音に
合わせる）と 4:2（第4部分音を上の音の第2部分音に合わせる）の中間です。C2 から下では、
6:3 と 8:4 の中間です。A2 と C2 の間では、判断に使う部分音の組が、鍵を下がるごとに前者から
後者へ移ります。C4 より上では 4:2 の比重が次第に小さくなります。C6 以上から始まる
オクターブでは、第4部分音が高すぎ、すぐに消えてしまって判断に使えないため、2:1 だけで
調律します。

A2 から上では、各鍵を、その鍵から始まるオクターブについてこの規則で決まる幅の、12分の1だけ
動かします。そのため、あるオクターブの実際の幅は、そこに含まれる12鍵それぞれについて規則で
決まる幅の平均になり、そのオクターブ自身について規則で決まる幅とは一致しません。鍵ごとの
硬さの変化が小さい C4 までは、両者の差は1セント以内です。高音域では、硬さが鍵を上がるごとに
大きくなるので、オクターブは規則で決まる幅より広くなります。

A2 より下では、規則で決まる幅が鍵ごとに大きく変わるので、この方法では分け合えません。
同じ方法を使うと、A1 と C2 のオクターブは規則で決まる幅の半分ほどになります。そこで
A2 より下の各鍵は、1オクターブ上の鍵から、その鍵自身のオクターブについて規則で決まる幅だけ
下に置きます。

幅は、弦が実際に鳴るときと同じ硬い弦の式と、鍵ごとの同じ硬さから求めます。そのため
String Stiffness で非調和性を変えると調律も一緒に動き、硬さ0ではピアノは厳密に平均律に
なります。A4 は 440 Hz のままです。ストレッチは打鍵時に決まるので、硬さのオートメーションは
鳴っている音ではなく次の音を調律し直します。

## 測定

`tools/eval/piano_stretch.py` は、2台のピアノの音から調律を読み取ります。1台は
Physical Piano で、工場設定の音をベロシティ0.7、48 kHz で鳴らします。もう1台は録音された
Steinway model B で、
[University of Iowa の Musical Instrument Samples](https://theremin.music.uiowa.edu/MISpiano.html)
にある mf の15音を使います。録音のいちばん低い音は B0 なので、A0 には録音の値がありません。

各セルの1つめの値が Physical Piano、2つめが Steinway です。単位はすべてセントです。基音と
聞こえる音高は、平均律からのずれで示します。Physical Piano は A4 = 440 Hz の平均律から、
Steinway はそのピアノ自身の A4 に合わせた平均律から測ります。Steinway の A4 は 440 Hz より
3.4セント高い位置にあります。オクターブの値は、下の音の部分音が、上の音でそれと重なるはずの
部分音よりどれだけ高いかを表します。0より小さければ2つの音はその純正なオクターブより
離れていて、0より大きければ近づいています。

| 鍵 | 基音 | 聞こえる音高 | 2:1 オクターブ | 4:2 オクターブ |
|---|---|---|---|---|
| A0 | -19.2 / – | +16.5 / – | -10.2 / – | -7.5 / – |
| B0 | -17.3 / -22.4 | +10.7 / +9.7 | -9.3 / -2.1 | -6.9 / -6.1 |
| C1 | -16.4 / -24.9 | +12.2 / +4.7 | -8.5 / -7.3 | -6.1 / -8.4 |
| A1 | -8.2 / -16.6 | +7.9 / +8.4 | -4.5 / -1.0 | -3.2 / -3.3 |
| C2 | -7.2 / -14.5 | +4.7 / +5.8 | -3.7 / -7.4 | -2.7 / -2.7 |
| A2 | -3.3 / -10.3 | +3.9 / +4.0 | -0.4 / +0.2 | +0.2 / +0.1 |
| C3 | -3.1 / -0.2 | +3.4 / +3.1 | -0.5 / -0.3 | +0.1 / +0.2 |
| C4 | -2.2 / -2.1 | +2.1 / +4.2 | -1.5 / -0.8 | -0.4 / +0.7 |
| A4 | -0.4 / 0.0 | +1.4 / +2.4 | -2.5 / -4.4 | 0.0 / -0.5 |
| C5 | +0.4 / +0.6 | +1.5 / +0.4 | -2.9 / -2.5 | +0.2 / +2.5 |
| C6 | +6.1 / +5.3 | +6.5 / +5.0 | -5.3 / -5.3 | – / – |
| C7 | +19.6 / +16.1 | – / +15.0 | -4.7 / – | – / – |
| C8 | +46.1 / -63.2 | – / – | – | – |

低音のオクターブは、この2列で読む部分音より高い部分音で調律します。同じオクターブを
6:3 と 8:4 で読んだ値は次のとおりです。

| 鍵 | 6:3 オクターブ | 8:4 オクターブ |
|---|---|---|
| A0 | -3.1 / – | +3.1 / – |
| B0 | -2.8 / +1.5 | +2.8 / 0.0 |
| C1 | -2.3 / -4.0 | +3.1 / -1.2 |
| A1 | -1.0 / -1.6 | +2.1 / -0.8 |
| C2 | -1.0 / -0.3 | +1.4 / -0.3 |
| A2 | +1.3 / +1.1 | +2.8 / +2.2 |

部分音は、まず、その音の平均律での周波数を整数倍した位置から150セント以内で、もっとも強い
周波数を探します。使うのは、打鍵の0.3秒後から2秒間にハン窓をかけたスペクトルです。
読み取る値は、その周波数から25セント以内にあるパワーの重心です。1つの鍵の弦どうしは完全には
同じ高さに調律されていないためで、録音の C7 では3本の弦が12セントの幅に広がっています。
2本のマイクで録音された信号は、それぞれのパワーを求めてから足し合わせます。聞こえる音高は、
音が繰り返す周期のことで、打鍵後0.05秒から0.55秒までの自己相関のピークから求めます。
波形を追うチューナーが示す値に当たります。耳の代わりに使う目安であり、聴覚のモデルでは
ありません。

### オクターブ

Physical Piano の A2 と C3 のオクターブは、純正な 2:1 と純正な 4:2 の間にあり、どちらからも
0.5セントほどしか離れていません。C4 から上のオクターブは、上で述べた平均のために、規則で
決まる幅より広くなります。A4 では純正な 4:2 に達しています。規則では 2:1 だけで調律する
C6 と C7 のオクターブは、純正な 2:1 より約5セント広くなっています。C2 から下のオクターブは、
純正な 6:3 と純正な 8:4 の間にあり、どちらからも1〜3セント離れています。

A2 から上では、Steinway の 2:1 と 4:2 の値はどれも、Physical Piano の値から2.5セント以内に
あります。C6 のオクターブが純正な 2:1 より5.3セント広い点も同じです。

B0 から C2 までの Steinway のオクターブは、純正な 8:4 から1.25セント以内にあります。
Physical Piano の弦は Steinway の弦と同じではないので、こちらは 6:3 と 8:4 の中間に調律して
います。こうすると、B0、A1、C2 の 4:2 の値は Steinway の値と1セント以内で一致し、C1 では
2セント狭くなります。純正な 8:4 に調律した場合は、4:2 の値が Steinway より1〜4セント広く
なります。2:1 の値の差はこれより大きく、最大7セントです。2:1 は上の音の基音と比べる値で、
録音の低音では、基音がその音自身の倍音より低い位置にあるためです。

### 基音

Physical Piano の基音は、A0 の19セント低い位置から C8 の46セント高い位置まで広がっています。
A4 の0.4セントは、調律ではなくユニゾンによるものです。1つの鍵の弦どうしは少しずらして
調律してあり、Unison Detune を0にすると A4 は0.0になります。

C3 から C7 までは、Steinway の基音との差が3.5セント以内です。C3 より下では Steinway の
ほうが5〜9セント低く、その一部は調律によるものではありません。録音の C2 では、第2部分音が
基音の2倍より6.9セント高い位置にあります。Physical Piano では0.4セントです。つまり録音の
基音は、その音自身の倍音に対して低い位置にあります。第2部分音で比べると、録音の C2 は
Physical Piano より1セント、C1 は6セント低くなっています。

### 聞こえる音高

Physical Piano の聞こえる音高は、C6 では基音と0.5セント以内で一致します。それより下では、
聞こえる音高に占める倍音の比重が大きくなり、音はその音自身の基音より高く聞こえます。その差は
C4 で4セント、C3 で7セント、C2 で12セント、A0 で36セントです。低音では調律で基音が
下がっていて、A0 ではこの36セントのうち19セントが、C2 では12セントのうち7セントが
打ち消されています。したがって、この読み取りでは、低音はまだ平均律より高く聞こえます。
A0 で17セント、B0 と C1 で11〜12セント、A1 で8セント、C2 で5セントです。

Steinway の低音も同じで、B0 から A2 まで4〜10セント高く聞こえます。B0 から C6 までは、
2台の聞こえる音高の差は約2セント以内です。例外は C1 で、Physical Piano のほうが7.5セント
高く聞こえます。録音の C1 は、その両隣の録音の音より低い位置にあります。

### 載せていない値と、値の確かさ

周期が定まらない音には、聞こえる音高を載せていません。Physical Piano の C7 と C8 は、周期を
読み取る0.5秒の間に減衰し、倍音が消えるにつれて周期が変わります。区間の両端より中央に重みを
つけて読み直すと、C7 は1.3セント、C8 は14セント低くなり、どちらも基音に近い値になります。
重みを変えただけで1セントより大きく動く聞こえる音高は、1つの値として示せません。

オクターブは、2つの部分音のどちらかが、その音のもっとも強い部分音を60 dBより大きく下回る
ときには載せていません。Physical Piano では C6 と C7 の第4部分音がこれに当たります。録音では
さらに、同じファイルの最後の2秒間に含まれる成分を10 dBより大きく上回る部分音だけを使います。
録音には、音が鳴っていない間も 8 kHz 付近に一定の成分が入っているためです。この条件で、
Steinway の C6 と C7 の第4部分音と、C7 の第2部分音が外れます。

録音の C8 は調律が狂っています。録音の C7 の1オクターブ上より79セント低く、C8 がどう
調律されるかの参考にはなりません。

読み取る区間を変えても、Physical Piano の値の動きは約0.5セント以内です。Steinway の値の
動きは2セント以内ですが、C7 の基音と C6 の 2:1 は2〜3セント動きます。比較の相手は、1台の
ピアノの1回の調律だけです。

### 測り直すには

```sh
cargo build --release -p auris-synth --example physical_fit_render
uv run tools/eval/piano_stretch.py prepare target/piano-stretch
uv run tools/eval/piano_stretch.py measure target/release/examples/physical_fit_render \
  target/piano-stretch.json --recorded target/piano-stretch
```

`prepare` は15個の録音（84 MB）をダウンロードし、
[piano-stretch-captures.json](../tools/eval/references/piano-stretch-captures.json) のハッシュと
照合します。`--recorded` を付けない `measure` は、Physical Piano だけを読み取ります。Windows
では、実行ファイルのパスの末尾に `.exe` が付きます。レポートには、丸める前のすべての値と、
聞こえる音高の2通りの読みが入ります。`tools/eval/test_piano_stretch.py` は、調律があらかじめ
分かっている合成の弦を使って、読み取りを確かめます。

## テスト

`auris-synth` の3つのテストが、この調律を保ちます。`a_piano_is_tuned_like_a_piano` は、
A4 を 440 Hz から0.6セント以内に、C1 を6〜30セント低く、C7 を6〜30セント高く保ち、
String Stiffness を0にしたときはどちらも平均律から1.5セント以内に保ちます。
`piano_octaves_lie_between_a_pure_two_to_one_and_a_pure_four_to_two` は、C3 と C4 の
オクターブを保ちます。下の音の第2部分音は、上の音の基音より高くても0.5セントまでです。
第4部分音は、上の音の第2部分音より0.5セント低いところから6セント高いところまでです。
`piano_bass_octaves_lie_between_a_pure_six_to_three_and_a_pure_eight_to_four` は、A0、C1、A1、
C2 のオクターブを保ちます。下の音の第6部分音は上の音の第3部分音より低く、第8部分音は
上の音の第4部分音より高く、その差はどちらも0.3〜6セントです。
