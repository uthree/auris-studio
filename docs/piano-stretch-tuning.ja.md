# 物理ピアノのストレッチ調律

[English](piano-stretch-tuning.md)

Physical Piano は以前、すべての基音を平均律（A4 = 440 Hz）ちょうどに置いていました。
弦には硬さがあるため、倍音は整数倍より高くなります。工場設定の硬さでは、テナー音域の
第8部分音は基音の8倍より約40セント高くなります。基音を平均律に置いたままでは、次の2つが
同時に起きていました。

* **低音が高く聞こえる。** 響板は200 Hz以下をあまり放射しないため、低い音の音高は倍音で
  聞こえます。レンダリングした音のチューナー読み（自己相関のピーク）は、C2〜C4 で7〜10セント、
  C1 と A0 で25〜33セント高く、高音域では0でした。
* **すべてのオクターブがうなる。** 鍵盤全体で、下の音の第4部分音が上の音の第2部分音より
  7.6セント、第2部分音が上の音の基音より1.8セント高くなっていました。

基音そのものは、44.1、48、96 kHz のどれでも、どのベロシティでも1セント以内で正確でした。
モーダル発振器には、ずれ得る分数遅延がありません。問題は発振器ではなく調律でした。

## 変更点

ピアノは調律師と同じやり方で調律されます。A4 から外側へ、各オクターブを、純正な 2:1
（下の音の第2部分音を上の音の基音に合わせる）と純正な 4:2（第4部分音を上の音の第2部分音に
合わせる）の中間まで広げます。A2 より下では基音が細くなるため、比例して高い部分音で
オクターブを判断します。A1 では 4:2 と 8:4、A0 では 8:4 と 16:8 です。幅は、弦が実際に鳴る
ときと同じ硬い弦の式と、音域で補正した同じ硬さから求めます。そのため String Stiffness で
非調和性を変えると調律も一緒に動き、硬さ0ではピアノは厳密に平均律になります。A4 は 440 Hz の
ままです。実装は `calibration::piano_stretch` です。ストレッチは打鍵時に決まるので、硬さの
オートメーションは鳴っている音ではなく次の音を調律し直します。

## 測定

工場設定の音、Body Resonance は既定値、ベロシティ0.7、48 kHz。値は平均律からのセントです。
オクターブは下の音の部分音から上の音の部分音を引いた値で、正なら広くうなるオクターブです。
部分音は0.3〜2.3秒の Goertzel ピーク、聞こえる音高は0.05〜0.55秒の自己相関ピークです。

| 鍵 | 基音 | 聞こえる音高 | 2:1 オクターブ | 4:2 オクターブ |
|---|---|---|---|---|
| A0 | +0.1 → -25.3 | +33.1 → +7.8 | +0.2 → -13.7 | +2.6 → -12.3 |
| C1 | +0.3 → -18.9 | +25.2 → +7.1 | +0.9 → -7.5 | +3.4 → -4.5 |
| A1 | +0.5 → -11.1 | +10.2 → -1.2 | +0.9 → +0.0 | +1.0 → -0.5 |
| C2 | +0.0 → -10.5 | +8.7 → -1.7 | +0.5 → -1.6 | +0.2 → -2.0 |
| A2 | -0.5 → -10.4 | +10.4 → +0.2 | +1.9 → -2.8 | +6.5 → +1.9 |
| C3 | -0.5 → -9.0 | +10.0 → +1.3 | +2.2 → -2.7 | +7.8 → +3.0 |
| C4 | -0.7 → -4.3 | +7.3 → +3.4 | +1.8 → -3.0 | +7.7 → +2.9 |
| A4 | -0.4 → -0.4 | +2.4 → +2.4 | +1.8 → -3.0 | +7.6 → +2.8 |
| C5 | -0.4 → +0.8 | +1.5 → +2.7 | +1.8 → -3.1 | +7.5 → +2.7 |
| C6 | -0.2 → +5.9 | +0.0 → +6.1 | +1.9 → -3.0 | +7.6 → +2.8 |
| C7 | -0.1 → +10.8 | +0.0 → +10.6 | +1.9 → -3.0 | +7.7 → +2.9 |
| C8 | +0.0 → +15.7 | +5.8 → +23.2 | – | – |

高音域は、実際のピアノと同じくチューナーでは高く読めます。コンサートグランドの C8 は
平均律より25〜35セント高いのが普通です。ここでのストレッチが小さいのは、実際の弦では高音域で
硬さが増えるのに、モデルの硬さはテナーの値のままだからです。C8 の周期は11サンプルしかないため、
その聞こえる音高の値は信頼できません。A4 に残る -0.4 セントは、デチューンしたユニゾンのうち
低い弦をハンマーが強めに打つことによるものです。

`piano_octaves_are_stretched_between_pure_two_one_and_four_two` がテナーのオクターブをこの釣り合いに
保ちます。以前の調律では、C3 の 4:2 オクターブが +7.8 セントでこのテストは失敗しました。
