# 物理ピアノのストレッチ調律

[English](piano-stretch-tuning.md)

Physical Piano は、基音を平均律ちょうどには置きません。弦には硬さがあるため、倍音は整数倍より
高くなります。すべての基音を平均律（A4 = 440 Hz）に置いたピアノでは、次の2つが同時に起きます。

* **低音が高く聞こえる。** 低い音の音高は倍音で聞こえるため、音は基音より高く聞こえます。
* **すべてのオクターブがうなる。** 下の音の第2部分音は上の音の基音より高く、第4部分音は
  上の音の第2部分音よりさらに高くなります。

## 調律のしかた

ピアノは調律師と同じやり方で調律されます。A4 から外側へ、各オクターブを、純正な 2:1
（下の音の第2部分音を上の音の基音に合わせる）と純正な 4:2（第4部分音を上の音の第2部分音に
合わせる）の中間まで広げます。A2 より下では基音が細くなるため、比例して高い部分音で
オクターブを判断します。A1 では 4:2 と 8:4、A0 では 8:4 と 16:8 です。C4 より上では 4:2 の
比重が次第に小さくなります。C6 以上から始まるオクターブでは、第4部分音が高すぎ、すぐに
消えてしまって判断に使えないため、2:1 だけで調律します。

幅は、弦が実際に鳴るときと同じ硬い弦の式と、鍵ごとの同じ硬さから求めます。そのため
String Stiffness で非調和性を変えると調律も一緒に動き、硬さ0ではピアノは厳密に平均律に
なります。A4 は 440 Hz のままです。ストレッチは打鍵時に決まるので、硬さのオートメーションは
鳴っている音ではなく次の音を調律し直します。

## 基音の位置

A4 から外側へ各オクターブが少しずつ広いため、実際のピアノと同じく、基音は低音域で平均律より
低く、高音域で高くなります。2つのテストがこれを保ちます。`a_piano_is_tuned_like_a_piano` は、
A4 を 440 Hz から0.6セント以内に、C1 を6〜30セント低く、C7 を6〜30セント高く保ち、
String Stiffness を0にしたときはどちらも平均律から1.5セント以内に保ちます。`piano_octaves_lie_between_a_pure_two_to_one_and_a_pure_four_to_two` は、C3 と C4 の
オクターブをこの釣り合いに保ちます。2:1 では広くても0.5セントまで、4:2 では0.5セント狭い
ところから6セント広いところまでです。
