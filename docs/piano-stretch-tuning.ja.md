# 物理ピアノのストレッチ調律

[English](piano-stretch-tuning.md)

Physical Piano は、基音を平均律ちょうどには置きません。弦には硬さがあるため、倍音は整数倍より
高くなります。すべての基音を平均律（A4 = 440 Hz）に置いたピアノでは、次の2つが同時に起きます。

* **低音が高く聞こえる。** 低い音の音高は倍音で聞こえるため、音は基音より高く聞こえます。
* **すべてのオクターブがうなる。** 下の音の第2部分音は上の音の基音より高く、第4部分音は
  上の音の第2部分音よりさらに高くなります。

## 調律のしかた

ピアノは調律師と同じやり方で、A4 から外側へ調律されます。最初に A3 から A4 までの
オクターブを置き、その幅を12鍵に均等に割り振ります。ほかの鍵は、すでに調律した鍵から
1オクターブ離れた位置に置きます。その幅は、2つの純正なオクターブの中間です。A2 から上では、
2:1（下の音の第2部分音を上の音の基音に合わせる）と 4:2（第4部分音を上の音の第2部分音に
合わせる）の中間です。C2 から下では、6:3 と 8:4 の中間です。A2 と C2 の間では、判断に使う
部分音の組が、鍵を下がるごとに前者から後者へ移ります。

幅は、弦が実際に鳴るときと同じ硬い弦の式と、鍵ごとの同じ硬さから求めます。そのため
String Stiffness で非調和性を変えると調律も一緒に動き、硬さ0ではピアノは厳密に平均律に
なります。A4 は 440 Hz のままです。ストレッチは打鍵時に決まるので、硬さのオートメーションは
鳴っている音ではなく次の音を調律し直します。

弦の硬さとこの規則は、どちらも下で読み取る録音の Steinway と照らし合わせてあります。
Physical Piano の弦の硬さは Steinway の弦の値に沿って決めてあり、その硬さでこの規則を
使うと、弦は Steinway の弦から1セント以内の位置に並びます。

## 測定

`tools/eval/piano_stretch.py` は、2台のピアノの音から調律を読み取ります。1台は
Physical Piano で、工場設定の音をベロシティ0.7、48 kHz で鳴らします。もう1台は録音された
Steinway model B で、
[University of Iowa の Musical Instrument Samples](https://theremin.music.uiowa.edu/MISpiano.html)
にある mf の28音を使います。録音のいちばん低い音は B0 なので、A0 には録音の値がありません。

各セルの1つめの値が Physical Piano、2つめが Steinway です。単位はすべてセントです。基音と
聞こえる音高は、平均律からのずれで示します。Physical Piano は A4 = 440 Hz の平均律から、
Steinway はそのピアノ自身の A4 に合わせた平均律から測ります。Steinway の A4 は 440 Hz より
3.4セント高い位置にあります。オクターブの値は、下の音の部分音が、上の音でそれと重なるはずの
部分音よりどれだけ高いかを表します。0より小さければ2つの音はその純正なオクターブより
離れていて、0より大きければ近づいています。

| 鍵 | 基音 | 聞こえる音高 | 2:1 オクターブ | 4:2 オクターブ |
|---|---|---|---|---|
| A0 | -15.0 / – | +15.0 / – | -9.1 / – | -6.7 / – |
| B0 | -14.5 / -22.4 | +10.8 / +9.7 | -8.7 / -2.1 | -6.5 / -6.1 |
| C1 | -14.2 / -24.9 | +12.8 / +4.7 | -8.1 / -7.3 | -5.9 / -8.4 |
| A1 | -5.3 / -16.6 | +7.9 / +8.4 | -3.0 / -1.0 | -2.1 / -3.3 |
| C2 | -5.4 / -14.5 | +5.3 / +5.8 | -3.3 / -7.4 | -2.4 / -2.7 |
| A2 | -2.0 / -10.3 | +4.2 / +4.0 | -0.2 / +0.2 | +0.4 / +0.1 |
| C3 | -1.7 / -0.2 | +3.4 / +3.1 | -0.1 / -0.3 | +0.3 / +0.2 |
| C4 | -1.3 / -2.1 | +2.3 / +4.2 | -0.5 / -0.8 | +0.2 / +0.7 |
| A4 | -0.4 / 0.0 | +1.2 / +2.4 | -1.8 / -4.4 | +1.5 / -0.5 |
| C5 | +0.1 / +0.6 | +1.1 / +0.4 | -2.7 / -2.5 | +2.3 / +2.5 |
| C6 | +5.4 / +5.3 | +5.7 / +5.0 | -4.9 / -5.3 | – / – |
| C7 | +15.9 / +16.1 | – / +15.0 | -10.9 / – | – / – |
| C8 | +39.6 / -63.2 | – / – | – | – |

低音のオクターブは、この2列で読む部分音より高い部分音で調律します。同じオクターブを
6:3 と 8:4 で読んだ値は次のとおりです。

| 鍵 | 6:3 オクターブ | 8:4 オクターブ |
|---|---|---|
| A0 | -2.8 / – | +2.7 / – |
| B0 | -2.6 / +1.5 | +2.6 / 0.0 |
| C1 | -2.2 / -4.0 | +3.0 / -1.2 |
| A1 | -0.5 / -1.6 | +1.6 / -0.8 |
| C2 | -0.9 / -0.3 | +1.2 / -0.3 |
| A2 | +1.3 / +1.1 | +2.7 / +2.2 |

部分音は、まず、その音の平均律での周波数を整数倍した位置から150セント以内で、もっとも強い
周波数を探します。使うのは、打鍵の0.3秒後から2秒間にハン窓をかけたスペクトルです。
読み取る値は、その周波数から25セント以内にあるパワーの重心です。1つの鍵の弦どうしは完全には
同じ高さに調律されていないためで、録音の C7 では3本の弦が12セントの幅に広がっています。
2本のマイクで録音された信号は、それぞれのパワーを求めてから足し合わせます。聞こえる音高は、
音が繰り返す周期のことで、打鍵後0.05秒から0.55秒までの自己相関のピークから求めます。
波形を追うチューナーが示す値に当たります。耳の代わりに使う目安であり、聴覚のモデルでは
ありません。

### 弦

オクターブや基音の値は、調律に加えて、弦の性質によっても変わります。そこで、このツールは
弦の性質も読み取ります。硬い弦の第 *n* 部分音は *n f* √(1 + *B n*²) の位置にあるので、
(*f*ₙ / *n*)² を *n*² に対して並べると直線になります。弦の硬さ *B* は、10 kHz より下の
部分音を最大40本使って引いたこの直線から求めます。同じ直線から、第1部分音が直線上に
あるとした場合の位置も分かります。最後の列は、実際の第1部分音がその位置からどれだけ離れて
いるかです。

3本以上の部分音を読める B0 から A5 までは、表の値はどの読み取り値とも10%以内で一致します。
C6 から A6 までは、録音で読める部分音が2本しかありません。2本では直線を確かめる材料が
ないので、この範囲の読み取り値には3分の1ほどの幅があります。A6 より上では第2部分音が
読めないため、表はその下の2オクターブと同じ傾きで延ばしてあります。

2台の違いは、いちばん低い部分音にあります。Physical Piano の部分音は直線の上にあり、
第1〜第3部分音のずれは最大でも0.15セントです。一方 Steinway では、A2 から下で第1部分音が
弦の直線より6〜11セント低い位置にあります。C2 から下では、第2部分音も2〜6セント、
第3部分音も1〜2.5セント低くなっています。

直線そのもので比べると、B0 から C6 までの鍵で、2台の調律の差は1セント以内です。例外は
C1 で、録音の C1 が5セント低い位置にあります。

### オクターブ

Physical Piano のオクターブは、A2 から上では純正な 2:1 と純正な 4:2 の中間に、C2 から下では
純正な 6:3 と純正な 8:4 の中間にあります。2つの値は符号が逆で、大きさは約1セント以内で
そろっています。

Steinway のオクターブも同じです。A2 から C6 までの 2:1 と 4:2 の値は、Physical Piano の値と
0.5セント以内で一致します。例外は A4 で、Steinway のオクターブのほうが2〜2.5セント広く
なっています。

B0 から C2 までの Steinway のオクターブは、純正な 8:4 から1.25セント以内にあります。
Physical Piano のオクターブは 6:3 と 8:4 の間です。8:4 で比べる部分音は、どちらのピアノでも
弦の直線の上にあります。一方、2:1 と 4:2 は上の音の第1・第2部分音と比べる値で、Steinway の
低音ではこの2つが直線より低い位置にあります。それでも 4:2 で読むと、2台の低音のオクターブは
近い値になります。B0、A1、C2 では1.25セント以内で一致し、C1 では2.5セントの差があります。

### 基音

Physical Piano の基音は、A0 の15セント低い位置から C8 の40セント高い位置まで広がっています。
A4 の0.4セントは、調律ではなくユニゾンによるものです。1つの鍵の弦どうしは少しずらして
調律してあり、Unison Detune を0にすると A4 は0.0になります。

C3 から C7 までは、Steinway の基音との差が1.5セント以内です。C3 より下では Steinway の
ほうが8〜11セント低くなっています。これは調律の差ではなく、Steinway の第1部分音が弦の
直線より低い位置にあるためです。

### 聞こえる音高

Physical Piano の聞こえる音高は、C6 では基音と0.5セント以内で一致します。それより下では、
聞こえる音高に占める倍音の比重が大きくなり、音はその音自身の基音より高く聞こえます。その差は
C4 で4セント、C3 で5セント、C2 で11セント、A0 で30セントです。低音では調律で基音が
下がっていて、A0 ではこの30セントのうち15セントが、C2 では11セントのうち5セントが
打ち消されています。したがって、この読み取りでは、低音はまだ平均律より高く聞こえます。
A0 で15セント、B0 と C1 で11〜13セント、A1 で8セント、C2 で5セントです。

Steinway の低音も同じで、B0 から A2 まで4〜10セント高く聞こえます。B0 から C6 までは、
2台の聞こえる音高の差は2セント以内です。例外は C1 で、Physical Piano のほうが8セント
高く聞こえます。録音の C1 は、弦の位置が低かった鍵です。

### 載せていない値と、値の確かさ

周期が定まらない音には、聞こえる音高を載せていません。Physical Piano の C7 と C8 は、周期を
読み取る0.5秒の間に減衰し、倍音が消えるにつれて周期が変わります。区間の両端より中央に重みを
つけて読み直すと、C7 は1.3セント、C8 は13セント低くなり、どちらも基音に近い値になります。
重みを変えただけで1セントより大きく動く聞こえる音高は、1つの値として示せません。

オクターブは、2つの部分音のどちらかが、その音のもっとも強い部分音を60 dBより大きく下回る
ときには載せていません。Physical Piano では C6 と C7 の第4部分音がこれに当たります。録音では
さらに、同じファイルの最後の2秒間に含まれる成分を10 dBより大きく上回る部分音だけを使います。
録音には、音が鳴っていない間も 8 kHz 付近に一定の成分が入っているためです。この条件で、
Steinway の C6 と C7 の第4部分音と、C7 の第2部分音が外れます。

録音の C8 は調律が狂っています。録音の C7 の1オクターブ上より79セント低く、C8 がどう
調律されるかの参考にはなりません。

読み取る区間を変えても、Physical Piano の値の動きは約0.5セント以内です。Steinway の値の
動きは2セント以内ですが、C7 の基音と C6 の 2:1 は2〜3セント動きます。Steinway の弦の硬さは、
読み取る区間や使う部分音の本数を変えると3%まで動き、A1 と C2 では8%動きます。弦の直線の
位置は、B0 から C2 までは2セントまで、それより上では約0.5セント動きます。比較の相手は
1台のピアノだけで、調律も1回分だけです。

### 測り直すには

```sh
cargo build --release -p auris-synth --example physical_fit_render
uv run tools/eval/piano_stretch.py prepare target/piano-stretch
uv run tools/eval/piano_stretch.py measure target/release/examples/physical_fit_render \
  target/piano-stretch.json --recorded target/piano-stretch
```

`prepare` は28個の録音（157 MB）をダウンロードし、
[piano-stretch-captures.json](../tools/eval/references/piano-stretch-captures.json) のハッシュと
照合します。`--recorded` を付けない `measure` は、Physical Piano だけを読み取ります。Windows
では、実行ファイルのパスの末尾に `.exe` が付きます。レポートには、丸める前のすべての値と、
聞こえる音高の2通りの読みが入ります。`tools/eval/test_piano_stretch.py` は、調律があらかじめ
分かっている合成の弦を使って、読み取りを確かめます。

## テスト

`auris-synth` の3つのテストが、この調律を保ちます。`a_piano_is_tuned_like_a_piano` は、
A4 を 440 Hz から0.6セント以内に、C1 を6〜30セント低く、C7 を6〜30セント高く保ち、
String Stiffness を0にしたときはどちらも平均律から1.5セント以内に保ちます。
`piano_octaves_lie_between_a_pure_two_to_one_and_a_pure_four_to_two` は、C3、C4、C5、C6 の
オクターブを保ちます。下の音の第2部分音は、上の音の基音より高くても0.5セントまでです。
第4部分音は、上の音の第2部分音より低くても0.5セントまでです。
`piano_bass_octaves_lie_between_a_pure_six_to_three_and_a_pure_eight_to_four` は、A0、C1、A1、
C2 のオクターブを、第6部分音と第3部分音、第8部分音と第4部分音の組で同じように保ちます。
どちらのテストも、逆向きのずれは6セントまでしか許しません。
