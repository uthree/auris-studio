# 物理ピアノのストレッチ調律

[English](piano-stretch-tuning.md)

Physical Piano は、基音を平均律ちょうどには置きません。弦には硬さがあるため、倍音は整数倍より
高くなります。すべての基音を平均律（A4 = 440 Hz）に置いたピアノでは、次の2つが同時に起きます。

* **低音が高く聞こえる。** 低い音の音高は倍音で聞こえるため、音は基音より高く聞こえます。
* **すべてのオクターブがうなる。** 下の音の第2部分音は上の音の基音より高く、第4部分音は
  上の音の第2部分音よりさらに高くなります。

## 調律のしかた

ピアノは調律師と同じやり方で調律されます。A4 から外側へ、各オクターブを、純正な 2:1
（下の音の第2部分音を上の音の基音に合わせる）と純正な 4:2（第4部分音を上の音の第2部分音に
合わせる）の中間まで広げます。A2 より下では基音が細くなるため、比例して高い部分音で
オクターブを判断します。A1 では 4:2 と 8:4、A0 では 8:4 と 16:8 です。C4 より上では 4:2 の
比重が次第に小さくなります。C6 以上から始まるオクターブでは、第4部分音が高すぎ、すぐに
消えてしまって判断に使えないため、2:1 だけで調律します。

各鍵は、その鍵から始まるオクターブについてこの規則で決まる幅の、12分の1だけ動かします。
そのため、あるオクターブの実際の幅は、そこに含まれる12鍵それぞれについて規則で決まる幅の
平均になり、そのオクターブ自身について規則で決まる幅とは一致しません。鍵ごとの硬さの変化が
小さい A2 から C4 までは、両者の差は1セント以内です。いちばん下のオクターブでは、規則で
決まる幅が鍵を上がるごとに小さくなるので、実際のオクターブは規則で決まる幅より狭く
なります。高音域では、硬さが鍵を上がるごとに大きくなるので、規則で決まる幅より広く
なります。

幅は、弦が実際に鳴るときと同じ硬い弦の式と、鍵ごとの同じ硬さから求めます。そのため
String Stiffness で非調和性を変えると調律も一緒に動き、硬さ0ではピアノは厳密に平均律に
なります。A4 は 440 Hz のままです。ストレッチは打鍵時に決まるので、硬さのオートメーションは
鳴っている音ではなく次の音を調律し直します。

## 測定

工場設定の音を、ベロシティ0.7、48 kHz で鳴らし、`tools/eval/piano_stretch.py` で読み取った
値です。単位はすべてセントです。基音と聞こえる音高は、平均律からのずれで示します。
オクターブの値は、下の音の部分音が、上の音でそれと重なるはずの部分音よりどれだけ高いかを
表します。0より小さければ2つの音はその純正なオクターブより離れていて、0より大きければ
近づいています。

| 鍵 | 基音 | 聞こえる音高 | 2:1 オクターブ | 4:2 オクターブ |
|---|---|---|---|---|
| A0 | -21.0 | +14.7 | -15.5 | -12.9 |
| C1 | -13.6 | +15.0 | -8.7 | -6.4 |
| A1 | -4.7 | +11.0 | -0.9 | +0.3 |
| C2 | -4.2 | +7.7 | -0.6 | +0.4 |
| A2 | -3.3 | +3.9 | -0.3 | +0.2 |
| C3 | -3.2 | +3.4 | -0.4 | +0.1 |
| C4 | -2.3 | +2.1 | -1.6 | -0.3 |
| A4 | -0.4 | +1.4 | -2.5 | 0.0 |
| C5 | +0.4 | +1.5 | -2.9 | +0.3 |
| C6 | +6.1 | +6.5 | -5.3 | – |
| C7 | +19.6 | – | -4.7 | – |
| C8 | +46.1 | – | – | – |

部分音は、その音の平均律での周波数を整数倍した位置から150セント以内で、もっとも強い
周波数として読み取ります。使うのは、音の0.3秒から2.3秒までにハン窓をかけたスペクトルです。
聞こえる音高は、音が繰り返す周期のことで、0.05秒から0.55秒までの自己相関のピークから
求めます。波形を追うチューナーが示す値に当たります。耳の代わりに使う目安であり、聴覚の
モデルではありません。

基音は、A0 の21セント低い位置から C8 の46セント高い位置まで広がっています。A4 の0.4セントは、
調律ではなくユニゾンによるものです。1つの鍵の弦どうしは少しずらして調律してあり、
Unison Detune を0にすると A4 は0.0になります。

A1 から C3 までのオクターブは、2つの純正なオクターブの間にあり、どちらからも1セント未満
です。C4 から上のオクターブは、上で述べた平均のために、規則で決まる幅より広くなります。
A4 では純正な 4:2 に達しています。規則では 2:1 だけで調律する C6 と C7 のオクターブは、
純正な 2:1 より約5セント広くなっています。A0 と C1 のオクターブは、この2列で読む部分音より
高い部分音で判断するので、どちらの純正なオクターブよりも広くなっています。

聞こえる音高は、C6 では基音と0.5セント以内で一致します。それより下では、聞こえる音高に
占める倍音の比重が大きくなり、音はその音自身の基音より高く聞こえます。その差は C4 で
4セント、C3 で7セント、C2 で12セント、A0 で36セントです。低音では調律で基音が下がっていて、
A0 ではこの36セントのうち21セントが、C2 では12セントのうち4セントが打ち消されています。
したがって、この読み取りでは、低音はまだ平均律より高く聞こえます。いちばん下のオクターブで
15セント、A1 で11セント、C2 で8セント、A2 で4セントです。

C7 と C8 には、聞こえる音高を載せていません。この2音は、周期を読み取る0.5秒の間に減衰し、
倍音が消えるにつれて周期が変わります。区間の両端より中央に重みをつけて読み直すと、C7 は
1.3セント、C8 は14セント低くなり、どちらも基音に近い値になります。重みを変えただけで
1セントより大きく動く聞こえる音高は、1つの値として示せません。オクターブは、2つの部分音の
どちらかが、その音のもっとも強い部分音を60 dBより大きく下回るときには載せていません。C6 と
C7 の第4部分音がこれに当たります。

```sh
cargo build --release -p auris-synth --example physical_fit_render
uv run tools/eval/piano_stretch.py target/release/examples/physical_fit_render \
  target/piano-stretch.json
```

Windows では、実行ファイルのパスの末尾に `.exe` が付きます。レポートには、丸める前の
すべての値と、聞こえる音高の2通りの読みが入ります。`tools/eval/test_piano_stretch.py` は、
調律があらかじめ分かっている合成の弦を使って、読み取りを確かめます。

## テスト

`auris-synth` の2つのテストが、この調律を保ちます。`a_piano_is_tuned_like_a_piano` は、
A4 を 440 Hz から0.6セント以内に、C1 を6〜30セント低く、C7 を6〜30セント高く保ち、
String Stiffness を0にしたときはどちらも平均律から1.5セント以内に保ちます。
`piano_octaves_lie_between_a_pure_two_to_one_and_a_pure_four_to_two` は、C3 と C4 の
オクターブを保ちます。下の音の第2部分音は、上の音の基音より高くても0.5セントまでです。
第4部分音は、上の音の第2部分音より0.5セント低いところから6セント高いところまでです。
