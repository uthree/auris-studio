# ミキサーの信号フロー

[English](mixer-graph.md)

ミキサーは **Signal flow** で開きます。各トラックまたはバスには、名前、フェーダー、パン、ミュート、ソロ、メーターを含むノードが1つあります。エフェクトは処理順のまま個別のノードとして表示されます。フェーダーの操作はすべてのインサートの後段に作用します。バスとマスターノードは入力信号を合算します。矢印は音声の流れる方向を示します。バイパスされたエフェクトもチェーン内に残ります。

トラックの右ポート、または最後のエフェクトの右ポートを、バスの左入力ポートへドラッグします。**Output** はストリップの出力先にユニティーゲインのポストフェーダー分岐を追加し、既存の出力をすべて保持します。**Sends** は独自のレベルとプリ／ポストフェーダータップを持つ分岐を追加します。マスターと複数のバスが同じストリップを同時に受け取れます。コンソールの **Output** メニューでは接続済みの出力先ごとにチェックを切り替えられます。ツールバーからバスを追加すれば、共有リターンや別の処理分岐を作れます。

サイドチェインを受け付けるエフェクトには、上端にポートがあります。別のストリップの出力ポートをそこへドラッグすると、そのストリップをキー信号にできます。出力、センド、サイドチェインの接続はすべて循環検証の対象です。接続によってソースへ戻る循環が生じる場合、ドキュメントや Undo 履歴が変わる前に拒否されます。

音声を運ぶ配線には、Atelierのオーディオ用の色を共通で使います。出力・センド・サイドチェインの役割はラベルと線種で識別でき、トラックの色を変えても配線の表示は変わりません。

| 接続 | 線 | ラベル |
| --- | --- | --- |
| Output | 実線 | Out |
| Send | 破線 | Send ID、レベル、該当時はプリフェーダー印 |
| Sidechain | 点線 | Sidechain |

キャンバス下の凡例には現在の色が表示されます。同じソースと出力先を共有する配線は、同じバスへの複数センドを含め、別々の曲線レーンを使います。ラベルは各レーンに沿って配置され、センドを個別に識別できます。

再生中は、実際に運んでいる信号に応じて配線が発光し、少し太くなります。出力、センド、サイドチェインはオーディオ用の色とそれぞれの線種を保ちます。短いハイライトは各ソースから出力先へ、曲線や折れ曲がりに沿って一定の視覚速度で移動します。薄くなる軌跡はソースの方向へ伸び、明るさは信号に従います。グラフツールバーの **Animate signals** をオフにすると、レベルの発光と方向矢印を残したまま移動するハイライトだけを止められます。この設定は記憶されます。センドには独自のゲインとプリ／ポストフェーダータップが表示され、インサートチェーンの配線には次のエフェクトの入力が表示されます。バイパスされたエフェクトのサイドチェインは無効です。リバーブやディレイの残響は Stop 後も表示され、音声とともに消えていきます。表示はメーターのように短いピークを保持して滑らかに下がります。測定は **Signal flow** を開いている間だけ行われ、音、プロジェクト、Undo 履歴は変えません。

配線またはそのラベルをクリックして選択します。選択すると、オーディオ用の色と線種を保ったままアクセントの輪郭が太くなります。Delete または Backspace を押すか、配線またはラベルを右クリックして **Delete connections** を選びます。Windows では Ctrl、macOS では Command を押しながらクリックすると、複数の配線を選択できます。まとめて削除しても Undo は1ステップです。Undo と Redo は、削除されたセンドのオートメーションを含め、実際のルーティングを復元します。接続を解除しても選択した分岐だけが削除されます。すべての出力を削除するとストリップは未接続になり、新しいマスタールートは作られません。細いインサートチェーン矢印はエフェクト順に従います。順序を変えるにはエフェクトメニューを使います。

トラックノードで **Add effect** を使います。名前からエフェクトを開き、**Enabled** を切り替えてバイパスするか、**Effect** メニューで順序変更、削除、サイドチェイン選択を行います。ゲイン、パン、ミュート、ソロ、メーター、センドレベルはトラックノードにあります。センドのコンテキストメニューではプリ／ポストフェーダータップの変更や削除を行えます。

ノードをドラッグしてワークスペースを整え、背景をドラッグまたはスクロールしてパンします。Shift を押しながら背景をドラッグすると、矩形でノードを選択できます。選択したノードには強調された境界線が表示され、選択中の任意のノードをドラッグすると間隔を保ったままグループを移動できます。グループ全体の移動は Undo/Redo の1ステップです。未選択のノードをクリックすると単独選択になり、空白をクリックすると選択が解除されます。Ctrl-click（macOS では Command-click）で個々のノードを切り替えます。**Arrange nodes** は依存関係を左から右に配置します。**Console** はチャンネルストリップを表示し、**Signal flow** はグラフに戻ります。どちらのビューも同じプロジェクトを編集し、Undo/Redo を共有します。Tab でコントロール間を移動でき、ルーティングとエフェクトメニューからも接続にキーボードでアクセスできます。

保存されるプロジェクトには、ルーティング、エフェクト順、パラメーター、センドのタップポイントに加え、ノードの位置、ズーム、パンが含まれます。グラフを配置または移動した後に保存すると、次回も同じ表示を復元できます。**Fit graph** で選んだ 50% 未満の縮尺も保存されます。ノードのドラッグは Undo の1ステップで、**Arrange nodes** も Undo できます。これらの操作はルーティングや他のプロジェクト編集と同じ履歴を共有します。ズームとパンは Undo/Redo の間も現在の状態を保ち、それ自体は履歴のステップを消費しません。レイアウトの変更とその Undo/Redo は音声を再構築しません。新しいノードには自動レイアウトが使われ、Undo で復元されたノードは以前の位置を保ちます。保存済みビューのないプロジェクトは、100% の自動レイアウトで始まります。システムのアーキテクチャは `auris_session::guide` に記載されています。

## MCP とライブエージェント

MCP はプロジェクトのハンドル／パスと `operation` オブジェクトを持つ `mixer_graph` を公開します。まず `{"action":"read"}` から始めます。ノードは名前やエフェクト位置に依存しない安定した `track:N`、`track:master`、`effect:N` の ID を使います。読み取りページは処理順で、`next_offset` でノード一覧を続けて取得できます。各ページにはそのノードの出力エッジも含まれます。トラックの `output_node` は末尾のインサート、またはトラック自体を示します。トラック ID と末尾エフェクト ID のどちらでも出力接続を指定できます。センドエッジには安定した `send_id` とプリ／ポストフェーダータップが含まれます。

実際の ID を読み取った後の例です。

```json
{"project":"/absolute/path/Song/Song.auris","operation":{"action":"connect","source":"track:1","target":"track:2","kind":"send"}}
```

同じ `mixer_graph` の operation オブジェクトは、組み込みの Claude、Codex、ネイティブ API エージェントで使われます。ライブ呼び出しでは、保存済みプロジェクトの `project` フィールドだけを省略します。

| 操作 | Operation action |
| --- | --- |
| グラフを読む | `read` |
| フェーダー／パン／ミュート／ソロ | `set_strip` |
| 出力を置換／分岐を追加または削除 | `set_outputs` / `connect` / `disconnect` |
| 設定済みセンドを作成／レベルまたはタップを変更 | `add_send` / `set_send` |
| ディテクターソースを置換または消去 | `set_sidechain` |
| インサートを追加／削除 | `add_effect` / `remove_effect` |
| 順序変更／バイパス | `move_effect` / `enable_effect` |
| ネイティブエフェクトのパラメーターを読み取り／設定 | `parameters` / `set_parameter` |

どちらのトランスポートも同じセッション操作と循環チェックを使います。無効なエッジや古いエッジは編集前に拒否されます。出力を接続すると他の出力を置き換えずに出力先が追加されます。接続解除では指定した分岐だけが削除され、空の出力リストは未接続のままです。センドやエフェクトを削除すると、そのオートメーションも削除されます。MCP は実際の変更をチェックポイント付きで保存し、読み取りと変更のない接続リトライでは書き込みません。ライブ編集は未保存のまま Undo 可能です。Read-only と Plan モードではグラフを閲覧できますが編集はできません。通常の Edit モードでは、既存の権限ポリシーに従い、接続解除やエフェクト削除の前に確認を求めます。
