# 音楽解析

[English](music-analysis.md)

Auris は、書かれた音符からコードを推定します。
CPU 上の Rust 信号処理と固定テンプレートを使い、学習済みモデルや GPU は必要ありません。

## デスクトップで使う

**解析** メニューから、選択したノートトラックや全トラックのコードを解析できます。
ミュートした素材と既知の打楽器は除外し、既定では四分音符ごとに解析します。
解析はバックグラウンドで進み、進捗表示からキャンセルできます。解析結果のパネルはメニューから開き直せます。

下書きにはコード候補とスコアを表示します。プレビューの上限は256区間で、JSONには全結果を含めます。
時刻は0始まりの四分音符単位です。

結果は明示的に受け入れるまでプロジェクトを変更しません。
コードの適用は認識した区間と無音区間を更新し、不明区間と範囲外のハーモニーを保持します。候補を1つずつ選んで適用することもできます。

各適用は1回のUndoで戻せます。ドキュメントを編集すると結果は無効になります。

## CLIとモデル向けツール

```sh
auris analyze-chords song.auris --track Piano --from-beat 0 --to-beat 32 --window-beats 1
auris analyze-chords song.auris --apply
```

拍は0始まりの四分音符単位です。`--track` は `id:number` も受け付け、省略時は全音程トラックを対象にします。
`--apply` はコードを適用してチェックポイント付きで保存します。
MCPとエージェントは同じセッション処理を `analyze_chords` で使います。スコアは確率ではなく一致度です。

上限は16,384コード区間です。検証コマンドとアルゴリズムの詳細は [English](music-analysis.md) を参照してください。
