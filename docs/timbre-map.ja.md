# 音色マップ

[English](timbre-map.md)

ライブラリ上部の **Timbre Map** を開きます。Auris は内蔵のメロディ楽器と、読み込んだ SoundFont のメロディプリセットをバックグラウンドで測定します。カウンターには完了したサウンド数が表示されます。実行中のスキャンは Cancel、Close、Escape で停止できます。別のフォントを読み込んだ後は **Rescan Library** を使ってください。試作版では1回のスキャンにつき最大512サウンドを受け付け、ドキュメントを置き換えるか新しいスキャンを開始するまで結果をメモリに保持します。

各点が1つのサウンドです。ホバーすると名前が表示され、クリックすると基準音を試聴できます。**All Sounds** リストから、重なった点にも到達できます。サウンドを選ぶと特徴空間で近い8つのサウンドが強調され、**Similar Sounds** に距離の近い順で表示されます。色は音響的な k-means グループを示すもので、名前付きの楽器分類ではありません。**Use on Selected Track** は、そのサウンドを Undo 可能な編集として適用します。閲覧と試聴はドキュメントを変更しません。内蔵サウンドを適用すると既定パッチに戻り、選択トラックがすでに同じ楽器を使っている場合も含めてインストゥルメントのオートメーションを消去します。ミキサー設定は維持されます。

試聴には選択した再生可能トラックを使い、なければ最初の再生可能トラックを使います。ミュート、フェーダー、インサート、ルーティングも適用されるため、比較にはミュートしていないドライなトラックを選んでください。プレビューは共通の RMS 目標とピーク上限に合わせます。マップを閉じると最後のプレビューが停止します。

<a id="measurement-and-coordinates"></a>
## 測定と座標

各ソースについて、MIDI 48、60、72 をベロシティ 0.45 と 0.85 で鳴らす6つの同一条件のトリガーを使います。保持は600 ms、ノートオフ後は400 msです。中央 C で高いベロシティの録音をプレビューに使います。基準条件のいずれかで無音になるソースは除外し、明示的に数えます。解析は常にプロジェクトのミキサーより前の楽器生出力を測定します。

各トリガーは決定論的な DSP 特徴量を93個提供します。

* 12個の MFCC（係数0を除く）について、アタック、保持中の本体、リリースそれぞれの平均と標準偏差を求め、72個の値にします。32個のメルフィルターは40 Hzから10 kHzとナイキスト周波数の低い方までを対象にします。正規化した対数エネルギーを計算する前にチャンネルのパワーを合計します。
* 既存のドラム解析スペクトルから、オンセット基準のアタック、本体、テールにおける低域・本体・高域のエネルギー比、対数重心、平坦度、ピーク集中度を求め、18個の値にします。
* オンセット遅延、取得エネルギーの90%に達するまでの時間、持続エネルギー比の3個です。

6つの特徴ブロックを対応する音高・ベロシティ条件を保ったまま連結し、カタログ全体で558次元を標準化します。定数次元はゼロになります。この空間のユークリッド距離で近傍検索と決定論的 k-means（サウンド数の平方根を丸め、要求グループ数を1〜12に制限）を行います。これらは探索的なグループなので、有用性は試聴で確認してください。

マップには標準化分散の保持割合とともに3つの主成分を表示します。軸は統計的な方向であり、明るさや減衰のような固定ラベルはありません。3次元距離は近似にすぎず、類似度の順序付けには常に558次元すべてを使います。カタログを変更して再スキャンすると、座標とグループの両方が変わることがあります。計算に事前学習済み重み、Python ランタイム、ネットワークサービス、GPU は必要ありません。

実装では `auris_dsp::timbre` が特徴を抽出して射影し、`Session::timbre_map_job` がワーカー用にソースをスナップショットし、`TimbreMap::nearest` が類似度検索に応答し、`Session::use_timbre_sound` が結果を適用します。数値テストはレベル／極性不変性、無音と不正な PCM、ランク2・3のテストデータでの PCA 距離保存、決定論的なグループ化、退化したカタログを対象にします。デスクトップのハーネステストでは、読み取り専用の閲覧と Undo 可能な適用を確認します。
