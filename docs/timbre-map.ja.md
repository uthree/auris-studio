# 音色マップ

[English](timbre-map.md)

ライブラリ上部の **音源を探す** を開くか、ライブラリの検索欄に入力して **音の性格で探す…** を選ぶと、入力した語をそのまま引き継いで開きます。Auris は内蔵のメロディ楽器と、読み込んだ SoundFont のメロディプリセットをバックグラウンドで測定します。完了数はステータスバーに表示され、実行中のスキャンは Cancel、Close、Escape で停止できます。別のフォントを読み込んだ後は **ライブラリを再解析** を使ってください。試作版では1回のスキャンにつき最大512サウンドを受け付け、ドキュメントを置き換えるか新しいスキャンを開始するまで結果をメモリに保持します。

ウィンドウは役割ごとに3列です。狭いウィンドウでは同じ順に縦に並びます。

* **マップ**：各点が1つのサウンドです。ホバーで名前、クリックで試聴。**類似度**・**音の特徴**・**エンベロープ** で配置を切り替え、ドラッグ、視点プリセット、キーボードで操作できる回転ボタンで向きを変えます。下の凡例が色のグループを示し、**AIで名前とアイコンを付ける** は凡例のそばにあります。
* **音源**：検索欄1つで音色名と印象語を同時に扱います。**エンベロープで絞り込む** で実測値の範囲を足せます。有効な条件（エンベロープの範囲や、選んだ音の「似ている音色」）はチップで表示され、1つずつ外せます。重なった点にも一覧から到達できます。
* **選んだ音**：グループ、試聴鍵盤、**選択トラックに適用**、**似た音を探す**、会話への添付、分類の修正、実測エンベロープ。

サウンドを選ぶとマップ上で近い8つが強調され、**似た音を探す** で一覧が近い12個に絞られます（特徴空間での距離順、小さいほど近い）。色は音響的な k-means グループを示すもので、名前付きの楽器分類ではありません。**選択トラックに適用** は、そのサウンドを Undo 可能な編集として適用します。閲覧と試聴はドキュメントを変更しません。内蔵サウンドを適用すると既定パッチに戻り、選択トラックがすでに同じ楽器を使っている場合も含めてインストゥルメントのオートメーションを消去します。ミキサー設定は維持されます。

点や一覧の音色を選ぶと C4 が鳴り、トラックのないプロジェクトでも試聴できます。「鍵盤で試聴 · C4〜C5」では半音ごとに音程を変えて確認できます。Tab と Space でも鍵盤を操作できます。「C4を再生」で基準音を繰り返し、「試聴を停止」で再生や準備を止められます。試聴はオーディオ出力に直接流れ、トラックやマスターのミキサー設定には影響されません。プレビューは共通の RMS 目標とピーク上限に合わせます。音色の切り替え、再スキャン、マップを閉じる操作、ドキュメントの置き換えで前の試聴をキャンセルします。

<a id="measured-envelope"></a>
## 実測エンベロープ

各サウンドについて、C2・C4・C6 を1音ずつベロシティ100で鳴らし、アタック・ディケイ・サステイン・リリースを実測します。音量が落ち着く（300 msの間 1 dB 以内）か、消える（ピークから −60 dB）か、4秒経つまで押し、ノートオフ後は 60 dB 下がるか4秒経つまで録ります。音量は 5 ms ごとのチャンネル合計パワーを 25 ms の中央値で平滑化したものです。

| 値 | 意味 |
| --- | --- |
| アタック（ms） | 聞こえ始め（ピーク −40 dB）からピーク −1 dB まで |
| ディケイ（ms） | ピークからサステインの ±1 dB に入るまで。持続しない音はピークから −60 dB まで |
| サステイン（dB） | 押している最後の 300 ms の中央値（ピーク比） |
| リリース（ms） | ノートオフから、その時点の音量より 60 dB 下がるまで（RT60） |

録音内に収まらないディケイとリリースは傾きから外挿し、`≈` を付けて表示します。減衰しない音は 30 秒超と表示されます。要約値は3音の中央値で、詳細欄には3音すべてを描きます。どの値もその音のピーク基準なので、音量には左右されません。

**エンベロープで絞り込む** では段階ごとに名前付きの範囲を選べます（アタック：速い ≤15 ms／中くらい／遅い ≥150 ms、ディケイとリリース：短い／中くらい／長い（ディケイ 300 ms・2 秒、リリース 200 ms・1 秒）、サステイン：保つ ≥−6 dB／下がる／消える ≤−30 dB）。範囲外の音は除外せず、外れ具合（時間は対数）で後ろに並べるため、条件が厳しすぎても近い音が返ります。**エンベロープ** 配置では、対数アタック・サステイン・対数リリースで点を置きます。

エージェントは `search_instruments` で同じ範囲を指定でき、結果には実測値と3音ぶんの値が付きます。

```json
{"request":{"mode":"character","envelope":{"attack_ms":{"max":10},"release_ms":{"min":800}},"limit":5}}
```

3音の測定はスキャンでいちばん重い部分なので、SoundFont プリセットとプラグインの結果は `<設定フォルダ>/cache/sound-envelopes.json` に保存し、ファイルのパス・サイズ・更新時刻と測定方式の版をキーに再利用します。内蔵楽器はコードなので毎回測定します。

<a id="measurement-and-coordinates"></a>
## 測定と座標

各ソースについて、MIDI 48、60、72 をベロシティ 0.45 と 0.85 で鳴らす6つの同一条件のトリガーを使います。保持は600 ms、ノートオフ後は400 msです。中央 C で高いベロシティの録音をプレビューに使います。基準条件のいずれかで無音になるソースは除外し、明示的に数えます。解析は常にプロジェクトのミキサーより前の楽器生出力を測定します。

各トリガーは決定論的な DSP 特徴量を93個提供します。

* 12個の MFCC（係数0を除く）について、アタック、保持中の本体、リリースそれぞれの平均と標準偏差を求め、72個の値にします。32個のメルフィルターは40 Hzから10 kHzとナイキスト周波数の低い方までを対象にします。正規化した対数エネルギーを計算する前にチャンネルのパワーを合計します。
* 既存のドラム解析スペクトルから、オンセット基準のアタック、本体、テールにおける低域・本体・高域のエネルギー比、対数重心、平坦度、ピーク集中度を求め、18個の値にします。
* オンセット遅延、取得エネルギーの90%に達するまでの時間、持続エネルギー比の3個です。

6つの特徴ブロックを対応する音高・ベロシティ条件を保ったまま連結し、カタログ全体で558次元を標準化します。定数次元はゼロになります。この空間のユークリッド距離で近傍検索と決定論的 k-means（サウンド数の平方根を丸め、要求グループ数を1〜12に制限）を行います。これらは探索的なグループなので、有用性は試聴で確認してください。

マップには標準化分散の保持割合とともに3つの主成分を表示します。軸は統計的な方向であり、明るさや減衰のような固定ラベルはありません。3次元距離は近似にすぎず、類似度の順序付けには常に558次元すべてを使います。カタログを変更して再スキャンすると、座標とグループの両方が変わることがあります。計算に事前学習済み重み、Python ランタイム、ネットワークサービス、GPU は必要ありません。

実装では `auris_dsp::timbre` が特徴を抽出して射影し、`Session::timbre_map_job` がワーカー用にソースをスナップショットし、`TimbreMap::nearest` が類似度検索に応答し、`Session::use_timbre_sound` が結果を適用します。数値テストはレベル／極性不変性、無音と不正な PCM、ランク2・3のテストデータでの PCA 距離保存、決定論的なグループ化、退化したカタログを対象にします。デスクトップのハーネステストでは、読み取り専用の閲覧と Undo 可能な適用を確認します。
