# クリップの演奏を整える

[English](performance.md)

MIDIクリップを選び、インスペクターの**Performance**を使います。これらのコントロールは作成済みクリップと生成クリップの両方で使えます。元のスコアを保ったまま、再生とMIDI書き出しを変更します。保存するとコントロールとシードが保存され、コントロールを無効にすると、その段階ではスコアの動作に戻ります。コントロールのドラッグは、元に戻せる1回の編集です。

ピアノロールとドラムエディターには、**Source**と**Performance**の2つのタブがあります。**Source**は保存されたノートを編集し、**Performance**はアーティキュレーションの挿入、タイミングとベロシティの変更、各ループ通過を含む、再生に送られるノートをプレビューします。プレビューはインスペクターのコントロールをドラッグしている間と、Undo／Redoの後に更新されます。読み取り専用なので、ノートを編集するときはSourceに切り替えます。2つのタブはスクロールとズームを共有するため、その場で比較できます。歌声のピッチ輪郭と編集可能なエクスプレッションレーンはSourceに残ります。

主コントロールの下にある**Ghost note settings**を開くと、密度、長さ、配置を個別に設定できます。16分音符の隙間、8分音符の裏拍、アタック前のピックアップ、または繰り返す小節パターンを選べます。Variationは、1小節またはループ通過で繰り返しパターンを新たに抽選する頻度を変えます。Densityは同じシード付きテイクから選ぶ位置を増減し、ラウドネスを変えても再抽選しません。新しいゴーストはピックアップが初期値です。**Preserve long rests and phrase endings**を使うと、4分音符2つを超える最後のテールと隙間を無音にします。**Ghost source**は生成対象を1つのMIDIピッチ（たとえばスネア）に制限できます。他のキットボイスはその下で再生を続けられます。既存のブラシ設定は、元の全密度16分音符グリッドと同じ配置エンジンを使います。

**Strum settings**は、8分音符または16分音符の連続した手のクロックを追加します。方向を交互にすると休符も手を進め、別のコードを挿入しても後続のストローク全体が反転することはありません。クロックは、クリップが小節途中で始まる場合も含めてプロジェクトの小節線に従います。新しいストロークは16分音符クロックを使い、既存ストロークは変更するまで攻撃クロックを保ちます。アップストロークは最高音から1～4音だけを弾き、独自のベロシティスケールを持ちます。ダウンストロークは低い音を強調できます。これは音高順を使い、ギターの運指モデルではありません。スキップされた音高はSourceに残ります。フリーズすると、クリップ外の非表示ノートを保ったまま、そのアタックが表示されるフレーズから明示的に削除されます。**弦ごとの時間**は、ストロークの長さを和音全体ではなく弦1本あたりで決めます。6弦の和音はパワーコードより長くかかり、一部の弦だけを弾くアップストロークは短くなります。**ストロークのばらつき**は、ストロークごとの速さと弦の間隔を少しずつ変えます。ばらつきは和音の位置から決まるので再現でき、0にするとすべての和音が同じ鳴り方になります。2つの音のどちらが先かを聞き分けるには15〜20 msほど必要なため、和音全体のずれが10 msほどを下回ると、すべての弦が同時に鳴ったように聞こえます。`lint_project` はそのようなギターのパートを報告し、`inspect_performance` は演奏された和音で実際に測ったずれを返します。

**Expression & groove**は、テイクのシードを変えずにタイミングの揺れとベロシティの揺れを分離します。主Humanizeコントロールは現在の比率を保ったまま両方をスケールします。Phrase swellは最初のアタックと最後のアタックの間にクレッシェンドとデクレッシェンドを加え、4分音符より長い休符で新しいフレーズを開始します。Beat accentは符号付きで、正は4分音符の拍、負は8分音符の裏拍を強調します。Push / lay backはクリップの開始位置を境界として、演奏をどちらの方向にも最大50 ms移動します。

**Shared motion**は、個別の変化とタイムラインに揃えたジェスチャーを混ぜます。同じアンサンブルグループを使うクリップは、トラック、音高、ループ境界をまたいでそのジェスチャーを共有しますが、個別のタイミングとベロシティの強度は適用されます。この共通パルスは120 BPMのヒューマナイズスケールで拍として測るため、開始テンポが違うクリップも一致します。個別成分はミリ秒スケールを保ちます。

**Groove reference**は、別のMIDIクリップの最初の演奏通過を16分音符グリッドに取り込みます。コピーするのはタイミングオフセットと相対的なダイナミクスであり、音高、長さ、ノート数ではありません。コードのアタックは各スロットで平均され、空の参照スロットでは対象を変更しません。パターンは参照クリップの長さにわたって繰り返し、グリッドに切り上げます。タイミングとダイナミクスには別々の強度があります。新しいグルーヴは他の段階の前に加わるため、後のストラムを潰しません。保存されたテンプレートは参照元から独立しており、そのクリップを編集または削除しても結果は変わりません。再度選択するとスナップショットを更新します。

| コントロール | 動作 |
| --- | --- |
| Swing | 8分音符または16分音符グリッドの裏拍を遅らせます。 |
| Gate | 保持中のノートを短くし、後続アーティキュレーションの空間を開けます。 |
| Brush strength | 無音の16分音符グリッド位置で、直前の同時コードを20 ms、最大ベロシティ30%で繰り返します。グリッドは各拍子の各小節線から始まります。書かれたノートがその区間にあればブラシはスキップされます。 |
| Slide strength | 次のアタック直前に中間MIDIピッチを1つ、直前のノートのベロシティ最大65%で挿入します。ノートの長さは最大60 ms、または直前のノートの長さの4分の1です。レガートでは直前のノートのテールをその分だけ短くし、短い休符なら保持できます。 |
| Mute strength | ノート内の最後の12 msを、元のベロシティ最大35%の同音高リトリガーに置き換えます。演奏元はリトリガー開始位置で終わり、リトリガーは元のリリースで終わります。前段階とクリップの切り詰め後に少なくとも8分音符保持されたノートだけが対象です。同音高のテールが衝突する場合はスキップします。保存されたスコアは変わりません。 |
| Stroke spread | 同時ノートを最初から最後まで0～100 msに広げます。低音から高音、高音から低音、交互の方向を選べます。リリース時刻は保たれ、ストロークは次のアタックと最短ノートによって制限されます。 |
| Humanize | 関連するタイミングとベロシティの変化を加えます。滑らかな4拍ジェスチャー、1拍ジェスチャー、より小さな個別差です。 |

アーティキュレーションの強度が0なら無効です。Slideは2半音以上の間隔と4分音符以下の隙間を持つ単音のラインをつなぎます。コードと重なったボイスは、ボイス割り当てが曖昧なためそのままです。中間ピッチは前のピッチへ向かう整数中点で、半音階になることもあります。MuteとBrushは短いMIDIノートなので、選択した音源によってミュート弦のように聞こえるか、再トリガーされた音として聞こえるかが決まります。楽器のキースイッチ・アーティキュレーションを選択したり、ピッチベンドを送ったりはしません。

インスペクターは、保存されたトランスポーズをGateより前に置き、役割固有のタイミングオフセットをHumanizeより前に置くなど、表の順に新しい段階を配置します。各段階は前段階の結果を見るため、ブラシをストロークしたり、挿入ノートをHumanizeしたりできます。既存のカスタムスタックは順序を保ちます。挿入は自分自身の段階へフィードバックしません。タイミング変更後、同じ音高の別ノートと重なる挿入ノートは短縮または省略されます。書かれたノートが優先され、スコープされたドラムボイス間でも同じです。

Humanizeはシードを保存します。同じアレンジを再び開いて再生すると同じ結果になり、異なるクリップループ通過では異なる変化になります。近い時刻はジェスチャーを共有しますが、音高には小さな個別差が残ります。タイミングスケールはテンポに依存しないミリ秒で、最大強度では公称6 ms、ティック丸め前は約18 msに制限されます。滑らかな混合は、ノートごとに独立したノイズより分散が小さくなります。対応する公称ベロシティスケールは、書かれたベロシティの6%です。

**Keep the Performance**は、挿入ノートを含む最初の通過の演奏をスコアへ書き込み、すべての演奏段階をクリアします。元に戻せます。フリーズしたループはそのテイクを繰り返します。生成クリップのレシピをフリーズする操作は別のコントロールです。

## 自動ピッチジェスチャー

楽器クリップで、Performanceの**Melodic expression**を開きます。ScoopとFallには別々の深さと長さのコントロールがあります。Vibratoには深さ、Hz単位のレート、開始遅延があり、100 msかけてフェードインし、リリースに向けてフェードアウトします。Melodic connectionはノート変更の両側の長さを制御します。出るノートは2つの音高の中点へベンドし、入るノートは同じ音高で始まって自身の音高へ落ち着きます。上行と下行は同じ規則です。接続された終端ではScoopまたはFallの代わりにこの遷移を使います。

モノフォニックな楽器トラックを使います。チャンネルのピッチベンドはそのトラックで鳴るすべてのボイスに影響します。重なったノート、コード、80 ms未満のノートには生成ジェスチャーを付けません。接続は60 msを超える隙間、または2オクターブを超える間隔で停止します。各アタック／リリースジェスチャーはノート長の半分で上限となります。長さとビブラートレートはテンポ変更を含む実経過時間に従います。生成ベンドはHumanizeを含む最終演奏ノートに従い、既存の±12半音の範囲で作成済みベンドに加算されます。

**Performance**タブには、ループ反復を含む結果のピッチラインと読み取り専用のベンドレーンが表示されます。コントロールは両方を即時更新します。**Keep the Performance**で最初の通過のベンドを編集可能な点として書き込むまで、Sourceノートと手描きカーブは変わりません。Undoは元のノート、点、コントロールを復元します。隙間とクリップ／ループ終端では生成ベンドをリセットしますが、書かれたベンド値は隙間でも適用されます。MIDI書き出しはこれらのカーブを含み、必要ならRPN 0で±12半音範囲を選ぶため、深いFallも書き出し後に再読み込みできます。内蔵楽器とCLAPノートエクスプレッション楽器は半音単位でベンドを受け取ります。ライブVST3とMIDIのみのCLAP再生はホスト既存の±2半音範囲を保持し、深いコントロール範囲はそれを受け付ける楽器で聞こえます。

エージェントは編集前後に`inspect_performance`を使い、保存されたコントロールと測定された効果を区別します。`slide`は中間ノートを挿入し、`pitch.glide_ms`は上記の連続接続を生成します。最初の通過の診断は、ノートの変更、コントローラーの寄与、適用できない条件を報告します。選択した楽器の応答を検証するには、なお音声比較が必要です。

**Auto modulation**は、Vibratoと同じモノフォニック適用条件、遅延、100 msのフェードイン、リリースフェードでCC1を送ります。深さはピッチビブラートから独立しているため、ピッチの深さを0のまま楽器のモジュレーションホイールを開けます。ホイールの効果は楽器が決めます。作成済みモジュレーションは保持され、生成された動きに加算されます。

**Long-note volume**は、少なくとも600 ms続くモノフォニックノートにCC7を送ります。アタックを短く保持し、早い位置で下げ、中間を低く保ち、遅いピークへ上げ、リリースを和らげます。Strengthはこの輪郭を既存の音量カーブと混ぜ、何も書かれていなければフル音量と混ぜます。隙間では作成済み音量を保ち、クリップ／ループ終端ではフル音量に戻します。SoundFontと内蔵メロディックシンセはCC7に応答し、ホスト楽器はMIDIチャンネル音量をサポートする必要があります。読み取り専用のPerformanceレーンには両方の生成コントローラーが表示されます。

**Volume shape**にはBowed（元の形）、Central swell、Crescendo、Decrescendo、Soft attack、Flatがあります。プリセットを選ぶと点が編集可能なグラフへコピーされます。グラフをクリックして点を追加し、ドラッグして移動し、内部の点を右クリックして削除できます。最初と最後の点は開始位置とリリース位置に留まりますが、音量は変更できます。Escapeはドラッグをキャンセルし、Undoはジェスチャー全体またはプリセット選択を復元します。横軸は各ノート長の0～100%で、上端はフル音量です。編集するとプリセットラベルは**Custom**になります。形状はクリップとともに保存され、再生、MIDI書き出し、Performanceプレビュー、Keep the Performanceで共有されます。個別のStrengthコントロールは引き続き形状へ混ぜるだけで、形状を選択・編集しても強度0はオンになりません。古い設定はBowed形状を保持します。

**Upper octave**と**Lower octave**は、それぞれ+12と-12半音にコピーを追加します。割合は元ノートに対するベロシティを設定します。範囲外のコピーはスキップされ、同じ音高で重なる場合は既存ノートがコピーより優先されます。開始とリリースが一致する正確なオクターブレイヤーは、メロディーのピッチとコントローラージェスチャーを共有します。それ以外の重なるボイスは自動チャンネルジェスチャーを抑制します。4つのコントロールはすべて0（オフ）が初期値です。Sourceノートとカーブは編集可能なままで、**Keep the Performance**は聞こえたノートとコントローラーを書き込み、Undoは設定を復元します。

編集可能な長いノートの音量輪郭はプロジェクトに保存されます。
