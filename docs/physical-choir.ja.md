# Physical Choir

[English](physical-choir.md)

インストゥルメントライブラリで **Physical Choir** を選び、通常のインストゥルメントトラックでノートまたはコードを演奏します。安定したプラグイン ID は `auris.physical.choir` です。4人の歌い手による持続する無歌詞の合唱母音をローカルで合成し、16音までポリフォニックに演奏できます。

<a id="controls"></a>
## コントロール

| コントロール | 効果 |
| --- | --- |
| Vowel (Oo / Ah / Ee) | 声道を連続的にモーフィングします。0は丸い「oo」、1は開いた「ah」、2は前寄りの「ee」です |
| Voice Size | 声道の長さを14〜20.5 cmで変えます。大きい声では同じ音高でも共鳴が低くなります |
| Ensemble Variation | 歌い手ごとの音律、ビブラートの速度／位相、ゆっくりした音高の揺れ、声道長の差を作ります |
| Breath | 声門の奥に閉じきらない隙間を残し、そこを抜ける気流に乱流を乗せます |
| Tone | 声帯を通った気流が声道に届くときの鋭さです。低いと柔らかく暗く、高いと明るくなります |
| Vibrato | 音高の揺れを半音単位で設定します。MIDI CC1 は最大0.3半音を加えます |
| Stereo Width | 歌い手をステレオ空間に広げます。0では合唱を中央に配置します |
| Attack / Release | 各ノートの立ち上がりとフェードを整えます |
| Level | 楽器の出力ゲインを設定します |

すべてのコントロールは通常のパラメーターエディター、プラグイン状態の保存、オートメーションレーンに対応します。Vowel と Voice Size の変更は、約20 msかけて鳴っている声道共鳴を移動させます。Width と出力ゲインの変更も同じ時間で平滑化されます。MIDI CC7 はチャンネルボリューム、CC11 はエクスプレッションを制御し、ピッチベンドは鳴っているノートに対して ±24半音で追従します。ノートオフは重なったユニゾンを含め、対応する保持中のノートを1つ解放します。all-notes-off は合唱全体を解放し、all-sound-off は共有のクリック除去エンベロープを使います。

既定パッチのアタックは244 ms、リリースは700 msです。アタックは歌い手の息にあたり、その3分の1の時点で肺の圧力が満ちます。声帯は、振動を始められるだけの圧力に達すると自分で鳴り始めます。C3〜C5付近の保持コードは伴奏パッドの出発点に適しています。母音値を下げてアタックを長くすると丸い背景テクスチャになり、Tone を上げてアタックを短くすると前面に出る合唱パートになります。リバーブをインサートすると周囲の部屋の響きを加えられます。

<a id="model-and-verification"></a>
## モデルと検証

波形はどこにも書かれていません。各歌い手は二質量モデル（Steinecke と Herzel による）の声帯を1組持ちます。下と上の2つの質量をばねでつないだもので、肺の圧力、その間を抜ける空気のベルヌーイ圧、左右の衝突によって自分で振動します。声帯が通す気流は、声道を戻ってくる圧力波に対して毎ステップ解いているので、喉と同じように声道が音源を押し返します。

歌い手が操るのは張力で、周波数ではありません。張力を上げると声帯の質量は小さく、ばねは硬くなります。ただし実際に出る高さは息の強さや母音でも変わるので、1周期ごとに高さを測って張力を音符へ近づけます。人が耳で音程を合わせるのと同じやり方です。各ノートは、その音を楽に出せる大きさの声帯（バスからソプラノまで）で歌い、元の音から大きくベンドすると声区が変わります。C2 から A5 までのすべての音を、どの母音でも8セント以内に保ちます。

声道は、短く細い喉頭前庭と、その先に並ぶ8区間の円筒でできています。各区間は双方向の分数遅延線を持ち、面積が変わる所で受動的に圧力波を散乱させます。広い咽頭に対して声帯が振動を始められるのは、この喉頭前庭があるからです。フィットした3つの断面形状の間を母音が補間し、唇の反射、分布損失、1次の唇放射が出力を形作ります。母音の第1共鳴を音が超えると声帯は止まってしまうので、そうした音では母音を「ah」側へ開き、さらに声道を短くして歌います。ソプラノが最高音域でしていることです。

母音プロファイル、工場出荷時の音源コントロール、声帯の閉じ具合、歌い手が息を押す強さは、VocalSet の実際の持続母音に、この声帯を通して合わせました。検証には別の歌い手を使っています。メル距離は学習用の歌い手で 0.071（以前の規定パルス音源では 0.072）、検証用の歌い手で 0.088（同 0.086）です。女声はどの母音でも以前より録音に近く、男声の「oo」が最も離れています。歌い手の解剖を測定したものではなく、楽器の音色を表します。

音源／フィルターと管の原理は Oxford phonetics の [tube-model practical](https://www.phon.ox.ac.uk/jcoleman/tubes_practical.html) に説明されています。[sndkit の声道の説明](https://pbat.ch/sndkit/tract/) では、関連する Kelly–Lochbaum 導波管の系統を説明しています。Auris は独自の圧力散乱実装、断面形状、分数区間遅延、合唱レンダラーを使います。声帯のモデル、耳で合わせる音程、フォルマント同調は、kishida 氏による物理モデルの歌声デモにならっています。

ユニットテストでは、物理的な4分の1波長共鳴、母音スペクトル、第1共鳴の表、合唱の音域全体での各音の音高、演奏音の基音、コードレベル、ステレオダウンミックス、コントローラー応答、ノート解放を測定します。ブロックサイズとリセットを変えた場合もサンプル単位で同じ出力になることを比較し、オートメーション、コントローラー変更、ボイススティール時のコールバック割り当てがゼロであることを数えます。セッションテストでは、母音オートメーション付きの通常のインストゥルメントトラックを保存して再オープンし、レンダリング音声を比較します。

編集可能なデモプロジェクトと、3種類のステレオ母音試聴を生成します。

```sh
cargo run -p auris-session --example choir_preview -- target/choir-preview
```

4コードのフレーズはすべての試聴で同じです。`choir-preview.auris` には既定の「ah」版が入り、`choir-oo.wav`、`choir-ah.wav`、`choir-ee.wav` はそれぞれ母音値0、1、2を使います。フレーズで使うのはこの楽器と通常のミックス出力だけです。

4コード試聴のピークは、クリッピングなしで oo が -10.36 dBFS、ah が -7.95 dBFS、ee が -8.81 dBFSです。C3〜G4 で母音ごとの音量を揃えているので、母音をオートメーションしても音量は揺れません。
