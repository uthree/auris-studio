Auris Studio is a digital audio workstation for macOS and Windows, written in Rust. Tell the agent what you want to hear, and it writes, plays back and revises real tracks you can keep editing by hand. Auris Studio は Rust で書かれた macOS / Windows 向けのデジタル・オーディオ・ワークステーションです。聴きたい音楽を言葉で伝えると、エージェントが実際のトラックを書き、鳴らし、直します。その結果は、そのまま手で編集し続けられます。

Free and open source · Apache-2.0 · macOS, Windows (CLI on Linux) 無料・オープンソース · Apache-2.0 · macOS、Windows（Linux は CLI）

One document, two hands on it ひとつの曲を、ふたりで触る

The agent edits the same project you do, through the same commands, so every change it makes is an ordinary step you can undo, tweak or keep. エージェントはあなたと同じプロジェクトを、同じコマンドで編集します。だからエージェントの変更はどれも、取り消しも手直しもできる普通の一手です。

AI workshopAIワークショップ

Describe a song: mood, instruments, length, lyrics. A director asks what it needs to know, then several composers write alternatives side by side for you to choose from. 雰囲気、楽器、長さ、歌詞などで曲を説明すると、ディレクターが必要なことを確認し、複数の作曲担当が候補を並行して書きます。その中から選ぶだけです。

An agent beside the editorエディタの隣にエージェント

Ask for a bass line, a reharmonisation or a mix pass while you work. Use Claude Code, Codex, OpenCode, local Ollama or any OpenAI-compatible API. 作業しながらベースラインやリハーモナイズ、ミックスの調整を頼めます。Claude Code、Codex、OpenCode、ローカルの Ollama、OpenAI 互換 API に対応します。

Composition from textテキストからの作曲

Write a song specification of sections, chords and style, or start from a preset, and a score-based composer writes it out. Every random choice is pinned by a seed. セクション、コード、スタイルを書いた曲の仕様やプリセットから、楽譜ベースの作曲エンジンが曲を書き出します。ランダムな選択はすべてシードで固定されます。

Instruments built inすぐ鳴る内蔵音源

Physically modelled piano, guitars, bass, strings, winds and choir, chiptune synths and SoundFont playback, with no sample library to download. 物理モデルのピアノ、ギター、ベース、弦、管、合唱に、チップチューン音源と SoundFont 再生。サンプルライブラリのダウンロードは不要です。

Singing voices歌声合成

Singer tracks carry lyrics on their notes and render them through DiffSinger, VOICEVOX and other singing backends. シンガートラックはノートに歌詞を持ち、DiffSinger や VOICEVOX などの歌声合成エンジンで歌わせられます。

A full DAW underneath中身はちゃんとしたDAW

Piano roll, audio recording with punch-in, automation, buses and sends, CLAP and VST3 plugins, MIDI import and export, and a GPU-drawn interface. ピアノロール、パンチイン録音、オートメーション、バスとセンド、CLAP / VST3 プラグイン、MIDI の読み書き、そして GPU で描画される UI。

The same commands at every door どの入り口からも、同じコマンド

The desktop, the auris command line and the auris-mcp server all drive one headless session, so a coding agent you already use can compose, render and check music too. デスクトップアプリ、auris コマンド、auris-mcp サーバーは、どれも同じヘッドレスなセッションを動かします。普段使っているコーディングエージェントからも、作曲、レンダリング、確認ができます。

Installインストール

Download the Windows installer or the macOS disk image from the releases page. The desktop, the auris CLI and auris-mcp ship together. リリースページから Windows 用インストーラーか macOS 用ディスクイメージをダウンロードしてください。デスクトップアプリ、auris CLI、auris-mcp が一緒に入っています。

Build from sourceソースからビルド

With Rust 1.95 or newer.Rust 1.95 以降が必要です。

git clone https://github.com/uthree/auris-studio.git
cd auris-studio
cargo run --release
